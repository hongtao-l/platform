# 服务商城/推荐位 — 支付方式展示规则 PRD

> 版本：v1.0 | 2026-07-14

---

## 一、业务背景

套餐（订阅制/非订阅）在不同 APP 中可配置多种支付方式，包括内购（Google Pay / Apple Pay）及非内购方式。若某支付方式缺少必要凭证（IAP Key）或不被当前售卖场景支持，应从 APP 端入口隐藏，避免用户点击后支付失败。

---

## 二、支付方式定义

| 支付方式 | 归属 | 是否支持订阅 | 说明 |
|----------|------|:---:|------|
| Google Pay | 内购 | 是 | Android 端 Google Play 内购 |
| Apple Pay | 内购 | 是 | iOS 端 App Store 内购 |
| 其他支付方式（预留） | 非内购 | 视平台而定 | 如支付宝、微信等，非内购渠道 |

> 当前版本内购渠道仅 Google Pay / Apple Pay，非内购渠道待后续接入。

---

## 三、核心业务规则

### BR-1：内购 Key 决定内购支付方式显隐

**来源**：套餐配置中按 `定价类型 × APP × 平台` 存储的内购 Key（参考《订阅非订阅独立内购Key PRD》BR-13）。

| Google Key | Apple Key | Android 端 | iOS 端 |
|:---:|:---:|:---:|:---:|
| 有 | 有 | 显示 Google Pay | 显示 Apple Pay |
| 有 | 空 | 显示 Google Pay | 不显示 Apple Pay |
| 空 | 有 | 不显示 Google Pay | 显示 Apple Pay |
| 空 | 空 | **该端不显示该套餐** |

> 判断按 **当前 APP × 当前用户选择的定价类型** 查找对应 Key。

---

### BR-2：仅内购套餐且 Key 未配置 → 套餐整体隐藏

当某套餐在某端仅有内购一种支付方式，但对应 Key 均为空时，**该套餐在该端不展示**。

```
条件：支付方式白名单仅包含内购 AND (Google Key 空 OR Apple Key 空)
结果：该套餐对该端不可见
```

---

### BR-3：仅内购且仅一种定价类型 Key 已配 → 隐藏定价切换

当套餐同时提供订阅制 + 非订阅两种定价，但某端仅有内购一种支付方式，且仅其中一种定价类型的 Key 已配置时：

- **隐藏定价切换按钮**（连续包月/年 等切换入口）
- 用户仅能以已配置 Key 的定价类型购买

```
条件：支持 sub + nonSub AND 支付方式仅内购 AND 仅 sub 的 Key 已配
结果：不显示"切换为一次性购买"入口，用户只能按订阅制购买（反之亦然）
```

---

### BR-4：订阅套餐禁止展示不支持订阅的支付方式

若某支付方式不支持订阅（如部分第三方支付仅支持一次性扣款），则订阅制定价的套餐**不应展示该支付方式**。

```
条件：用户选择订阅制定价 AND 支付方式不支持订阅
结果：过滤该支付方式
```

> 当前内购（Google Pay / Apple Pay）均支持订阅，此规则为后续非内购渠道预留。

---

### BR-5：地区支付方式白名单

后台支持按 **APP × 地区（国内/海外）** 配置可用支付方式白名单。

| 配置维度 | 说明 |
|----------|------|
| APP | 牵心PRO / 鹤梦之家 |
| 地区 | 国内 / 海外 |
| 白名单 | 该 APP 在该地区可用的支付方式集合 |


## 四、涉及范围

| 模块 | 影响 |
|------|------|
| 套餐配置（后台） | 新增支付方式白名单配置入口（按 APP × 地区） |
| 服务商城（APP 端） | 按规则过滤展示 |
| 推荐位（APP 端） | 同商城逻辑 |
| 套餐管理 API | 套餐接口返回新增 `availablePaymentMethods` 字段 |

## 五、测试要点

| 编号 | 场景 | 预期 |
|------|------|------|
| T-01 | 订阅 Key 已配 + 非订阅 Key 未配 + 仅内购 | 隐藏定价切换，只显示订阅制购买 |
| T-02 | 两种定价 Key 均已配 | 显示定价切换按钮 |
| T-03 | Google Key 空 + Apple Key 已配 + iOS 端 | 显示 Apple Pay，不显示 Google Pay |
| T-04 | 两种 Key 均为空 + 仅内购 | 该套餐不显示 |
| T-05 | 两种 Key 均为空 + 有非内购 | 显示非内购支付方式 |
| T-06 | 国内地区 + 白名单无 Google Pay | 不显示 Google Pay |
| T-07 | 海外地区 + 白名单仅内购 | 按 Key 配置显隐内购方式 |
| T-08 | 订阅制 + 支付方式不支持订阅 | 过滤该支付方式 |
