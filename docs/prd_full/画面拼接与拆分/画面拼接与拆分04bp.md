## 一、核心指标体系

### 1.1 指标总览

| 序号 | 指标名称 | 指标类型 | 计算方式 | 目标值 | 监控周期 |
|---|---|---|---|---|---|
| M-01 | 配置覆盖率 | 业务 | 已开启画面拼接/拆分的摄像机产品数 ÷ 摄像机产品总数 | ≥ 30%（上线后 3 个月） | 周 |
| M-02 | 模式分布占比 | 业务 | 拼接产品数 / 拆分产品数 分别 ÷ 已开启产品数 | 视机型结构，无硬目标 | 周 |
| M-03 | 单产品平均 Camera 数 | 行为 | 拆分配置中 Camera 数量总和 ÷ 拆分模式产品数 | 参考值 1.5 左右 | 月 |
| M-04 | 配置保存成功率 | 质量 | 保存成功次数 ÷ 保存请求次数 | ≥ 99% | 日 |
| M-05 | 直播画面降级率 | 质量 | 降级为单画面的直播次数 ÷ 有配置的直播次数 | ≤ 3% | 日 |
| M-06 | 配置进入率 | 行为 | 进入默认配置 Tab 后展开本配置的会话数 ÷ 进入默认配置 Tab 的会话数 | ≥ 40% | 周 |
| M-07 | 分割点自定义率 | 行为 | 修改过分割点的 Camera 数 ÷ 全部 Camera 数 | 参考值 20%~40% | 月 |
| M-08 | 直播首帧成功率（含拆分） | 质量 | 拆分/拼接配置下首帧成功次数 ÷ 对应直播次数 | ≥ 98% | 日 |

### 1.2 指标详细说明

**M-01 配置覆盖率**
- 业务含义：有多少摄像机产品真正用上了这个配置项。低于预期说明要么品类不需要，要么配置入口不够显眼。
- 为什么选它：这是本需求"减少 APP 发版"价值的直接体现。
- 波动原因：新产品未及时配置、配置人员不了解入口。**应对**：产品上线流程中增加该配置项的检查节点。

**M-05 直播画面降级率**
- 业务含义：配置的子画面数量与设备实际流数不匹配的比例。
- 为什么选它：降级虽然是兜底，但降级率高说明**配置错误**或**设备上报与实际不符**，用户看到的画面和配置页描述不一致，容易产生客诉。
- 波动原因：某一机型批量配错、设备固件更新后流数变化。**应对**：按机型下钻定位，必要时回滚该机型配置。

**M-07 分割点自定义率**
- 业务含义：用户是否真的需要调分割点。若长期接近 0，说明默认均分已够，后续可考虑隐藏该选项简化操作。
- 为什么选它：直接指导下一版是否简化配置项。

## 二、埋点方案

### 2.1 事件清单

| 事件ID | 事件名称 | 触发时机 | event_type | 优先级 |
|---|---|---|---|---|
| `split_config_view` | 查看画面拼接/拆分配置 | 进入「默认配置」Tab 且该配置项完成渲染 | 0 | P1 |
| `split_enable_toggle` | 切换总开关 | 开关值变更并完成渲染 | 1 | P0 |
| `split_mode_select` | 选择模式 | 单选切换完成 | 1 | P0 |
| `split_camera_add` | 添加 Camera | 添加成功并切换到新 Camera 后 | 1 | P1 |
| `split_camera_delete` | 删除 Camera | 删除成功并切换后 | 1 | P1 |
| `split_camera_delete_blocked` | 删除被拦截 | 仅剩 1 个 Camera 时点击删除 | 2 | P1 |
| `split_pane_count_change` | 修改子画面数量 | 下拉选择完成 | 1 | P1 |
| `split_point_edit` | 修改分割点 | 输入框失焦且值发生变化 | 1 | P1 |
| `split_config_save` | 保存画面拼接/拆分配置 | 保存请求返回成功 | 1 | P0 |
| `split_config_save_fail` | 保存失败 | 保存请求超时或返回失败 | 2 | P0 |
| `live_split_render` | 直播按配置呈现 | 直播首帧渲染完成 | 1 | P0 |
| `live_split_fallback` | 直播降级为单画面 | 检测到实际流数 < 配置子画面数 | 2 | P0 |

> 前 10 个为管理后台埋点，后 2 个为 APP 直播端埋点。

### 2.2 公共参数（所有事件必带）

| 参数 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| event_type | String | 是 | 0=普通事件，1=额外参数事件，2=错误事件 | "1" |
| event_id | String | 是 | 事件ID | "split_mode_select" |
| event_time | Int64 | 是 | 事件发生时间戳(ms) | 1762675200000 |
| user_id | String | 是 | 用户唯一标识 | "usr_123456" |
| session_id | String | 是 | 会话ID | "sess_abc123" |
| app_id | String | 是 | 应用ID | "iot_platform" |
| app_version | String | 是 | 应用版本号 | "1.4.2" |
| brand | String | 是 | 手机品牌 | "apple" |
| os_type | String | 是 | 系统类型 | "iOS" |
| os_version | String | 是 | 手机系统版本 | "17.0" |
| company_id | String | 是 | 用户从属企业ID | "0000213ed0cdb8bc" |
| country | String | 是 | 国家 | "CN" |
| city | String | 是 | 城市 | "深圳" |

> 公共参数固定 13 项，不可增减。

### 2.3 业务参数（按事件）

**split_config_view**（event_type = 0）

无业务参数。

**split_enable_toggle**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| enable | String | 是 | 切换后的值，0=关闭 / 1=开启 |
| previous_enable | String | 是 | 切换前的值 |

**split_mode_select**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| mode | String | 是 | stitch=拼接 / split=拆分 |
| previous_mode | String | 是 | 切换前的模式 |

**split_camera_add**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| camera_count_after | Int | 是 | 添加后的 Camera 总数（1~4） |

**split_camera_delete**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| camera_count_after | Int | 是 | 删除后的 Camera 总数 |

**split_camera_delete_blocked**（event_type = 2）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| block_reason | String | 是 | 固定值 `last_camera` |

**split_pane_count_change**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| camera_name | String | 是 | Camera 名称，如 Camera_1 |
| pane_count_before | Int | 是 | 修改前子画面数量 |
| pane_count_after | Int | 是 | 修改后子画面数量 |

**split_point_edit**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| camera_name | String | 是 | Camera 名称 |

**split_config_save**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| product_id | String | 是 | 产品ID |
| enable | String | 是 | 提交时的开关值 |
| mode | String | 是 | 提交时的模式 |
| camera_count | Int | 是 | 提交时 Camera 数量（拼接模式下为 0） |

**split_config_save_fail**（event_type = 2）

| 参数 | 类型 | 必填 | 说明 |

| 参数 | 类型 | 必填 | 说明 |

| actual_stream_count | Int | 是 | 设备实际输出的流数量 |

**live_split_fallback**（event_type = 2）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| device_id | String | 是 | 设备ID |
| product_id | String | 是 | 产品ID |
| configured_pane_count | Int | 是 | 配置的子画面数量 |
| actual_stream_count | Int | 是 | 设备实际输出的流数量 |

### 2.4 上报方式

```
POST /api/{module}/event
```

### 2.5 去重策略

| 场景 | 策略 |
|---|---|
| `split_config_view` | 同一会话内同一产品只上报一次 |
| `split_point_edit` | 同一 Camera 连续输入合并，失焦后上报最终值 |
| `live_split_render` | 同一 device_id 同一会话内每次进入直播上报一次，切换清晰度不重复上报 |
| `live_split_fallback` | 同上，且与 `live_split_render` 同时上报，不单独去重 |

### 2.6 数据校验

| 校验项 | 规则 | 异常处理 |
|---|---|---|
| pane_count | 取值 2/3/4；读取时为 1 表示单画面 | 越界数据丢弃，计入脏数据日志 |
| split_points | 逗号分隔整数，严格递增，每个值 1~99 | 格式不符则丢弃该字段，事件保留 |
| mode / configured_mode | 枚举值必须在白名单内 | 非法值归入 `unknown` |
| camera_count | 0~4 | 越界丢弃 |
| 时间戳 | 与服务端时间偏差 ≤ 24 小时 | 超出范围标记并单独统计 |

## 三、数据看板

### 3.1 看板概览

| 项 | 内容 |
|---|---|
| 看板名称 | 画面拼接/拆分配置看板 |
| 看板用途 | 监控配置采纳情况、配置质量与线上呈现效果 |
| 目标人群 | 产品经理、运营、研发负责人 |

### 3.2 看板布局

```
区域 1：核心指标卡片区
- M-01 配置覆盖率（大字 + 环比）
- M-05 直播画面降级率（大字 + 红色高亮阈值 3%）
- M-04 配置保存成功率
- M-07 分割点自定义率

区域 2：趋势与结构
- 折线图：配置覆盖率 / 降级率 按周趋势（双轴）
- 饼图：模式分布（拼接 vs 拆分）
- 柱状图：单产品 Camera 数量分布（1/2/3/4）

区域 3：明细表格区
- 列：产品ID、产品名称、类目、模式、Camera 数、子画面数、最后配置时间、近 7 天直播降级率
- 筛选：按类目、模式、是否有降级
- 排序：降级率降序（默认）

区域 4：异常下钻
- 降级明细：设备ID、产品ID、配置子画面数、实际流数、发生时间
- 保存失败明细：产品ID、失败原因、发生时间
```

### 3.3 报表需求

| 报表名称 | 报表类型 | 数据维度 | 刷新频率 | 接收人 | 备注 |
|---|---|---|---|---|---|
| 画面拼接/拆分配置周报 | 周报 | 产品 / 类目 / 模式 | 每周一 | 产品、运营 | 含配置覆盖率与模式分布 |
| 直播降级明细日报 | 日报 | 设备 / 产品 / 机型 | 每日 | 研发、质量 | 降级率 > 3% 时附 Top10 |
| 配置保存失败报表 | 实时 | 产品 / 失败原因 | 实时 | 研发 | 用于快速定位接口异常 |

### 3.4 告警规则

| 告警名称 | 触发条件 | 告警级别 | 通知方式 | 接收人 |
|---|---|---|---|---|
| 直播降级率超标 | 当日降级率 > 5% 且样本量 ≥ 100 | P1 | 企业微信 | 研发负责人、产品 |
| 单机型集中降级 | 同一产品当日降级率 > 20% | P1 | 企业微信 | 产品、研发 |
| 保存失败率超标 | 1 小时内保存失败率 > 10% | P1 | 企业微信 | 研发 |
| 配置覆盖停滞 | 连续 14 天配置覆盖率无增长 | P2 | 邮件 | 产品、运营 |

## 四、数据字典

### 4.1 枚举定义

| 字段 | 取值 | 含义 |
|---|---|---|
| enable | 0 / 1 | 关闭 / 开启 |
| mode | stitch / split | 拼接 / 拆分 |
| configured_mode | off / stitch / split | 关闭 / 拼接 / 拆分 |
| render_mode | single / stitch / split | 单画面 / 拼接 / 拆分呈现 |
| pane_count | 1 / 2 / 3 / 4 | 子画面数量，1 表示未拆分 |
| fail_reason | timeout / network / server_error / permission | 超时 / 网络异常 / 服务异常 / 权限不足 |
| event_type | 0 / 1 / 2 | 普通事件 / 业务参数事件 / 错误事件 |

### 4.2 事件与异常场景对应关系

| 需求文档异常编号 | 对应埋点 |
|---|---|
| E-001 网络异常 | `split_config_save_fail`（fail_reason=network/timeout） |
| E-002 权限不足 | `split_config_save_fail`（fail_reason=permission） |
| E-004 并发冲突 | `split_config_save_fail`（fail_reason=server_error） |
| E-007 最后一个 Camera 不可删 | `split_camera_delete_blocked` |
| E-008 ~ E-011 分割点非法 | `split_point_edit`（auto_corrected=1） |
| E-015 直播降级 | `live_split_fallback` |
