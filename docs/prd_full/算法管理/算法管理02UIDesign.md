## 1. 页面结构（实际实现）

```
IoT 管理后台
│
├── 物模型管理
│   ├── 能力库
│   │   └── Tab: 标准能力 / 自定义能力 / 旧版能力
│   │       └── 能力池（含「算法能力模块」等多模块）
│   │
│   ├── 算法库（物模型路由版）          ← 精简版
│   │   ├── 搜索栏 + 表格 + 分页
│   │   ├── 添加/编辑算法弹窗
│   │   ├── 关联事件侧边抽屉
│   │   └── 算法能力详情二级页
│   │
│   └── 算法能力详情                   ← 二级页
│       ├── 返回栏 + 左栏模块侧栏 + 右栏能力表格
│       ├── 关联能力穿梭框（按模块分组）
│       └── 编辑能力参数弹窗
│
├── 算法管理（主入口）                  ← 独立菜单
│   ├── Tab: 算法库
│   │   ├── 搜索栏 + 表格 + 分页 + 空态
│   │   ├── 添加/编辑算法弹窗（720px）
│   │   └── 删除确认
│   └── Tab: 事件库
│       ├── 搜索栏 + 表格 + 分页 + 空态
│       ├── 添加/编辑事件弹窗（560px）
│       └── 删除确认
│
├── 套餐管理
│   └── 服务类型
│       └── 服务编辑弹窗（无 Tab，只读反显「已绑定物模型」列表）
│
└── 产品开发
    └── 继续开发
        ├── Step 2：设备算法服务（合并单元格表格 + 能力/事件配置 + 免开通）
        └── Step 3：平台服务（精简表格：服务ID/名称/描述/是否支持，不含免开通和套餐绑定）
```

**关键变更**（对比旧版文档）：
- 事件库不再嵌套在「能力库→标准能力」下，而是与算法库并列在同一页面的 Tab 中。
- 存在两个算法列表入口（主入口和物模型路由版），共用同一数据存储。
- 算法管理页有独立菜单入口，不在物模型管理菜单路径下。
- 算法新增「算法类型」（设备/平台），列表和编辑弹窗均已支持。
- 算法新增「关联服务」，通过算法库侧边抽屉编辑；服务类型弹窗改为只读反显「已绑定物模型」，不再提供三 Tab 穿梭框主动绑定。
- 产品开发 Step 3 平台服务精简为四列（服务ID/服务名称/描述/是否支持），移除算法级明细列。
- 算法列表列头由「AlgorithmID」改为「算法ID（AIIOTTYPE）」。
- 产品开发阶段不绑定套餐；免开通仅 Step 2 设备算法服务支持（前提：是否支持已开启）。产品审核阶段算法服务配置和平台服务均支持免开通+绑定套餐。

## 2. 布局详述

### 2.1 算法管理页面

整体使用带边框样式的标签页，包含两个 Tab。

#### Tab 1：算法库

##### 搜索栏
| 属性 | 说明 |
|------|------|
| 位置 | 页面上方，两侧分布 |
| 左区 | 文本输入框（240px，placeholder「搜索 AlgorithmID / 名称」）+ 「查询」+「重置」 |
| 右区 | 「添加算法」按钮（含加号图标） |
| 交互 | 回车触发查询；重置清空搜索框并刷新列表 |

##### 表格
| 列 | 宽度 | 样式 |
|------|------|------|
| 算法ID（AIIOTTYPE） | 180px | 代码风格标签 |
| 图标 | 70px，居中 | 18px emoji/icon；支持图片 URL（28×28）和 emoji 两种 |
| 算法名称 | min-width: 140px | 加粗，展示中文名称 |
| 算法类型 | 80px，居中 | 设备（默认标签）/ 平台（warning 类型标签） |
| 能力标签 | min-width: 260px | 小号圆角标签排列，最多显示 5 个 + `+N`；无能力时显示「配置」 |
| 关联事件 | 100px，居中 | 小号绿色标签显示数量，可点击；无事件时显示「配置」 |
| 关联服务 | min-width: 140px | 服务ID标签排列，可点击打开侧边抽屉；无服务时显示「配置」 |
| 引用设备 | 100px，居中 | 纯数字 |
| 操作 | 140px，居中，固定右侧 | 「编辑」「删除」

##### 分页
- 左侧「共 N 条记录」+ 右侧分页组件（支持切换每页条数、翻页）
- 每页条数: 10 / 20 / 50，默认 20
- 顶部分割线与上方表格分隔

#### Tab 2：事件库

##### 搜索栏
与算法库布局一致。

##### 表格
| 列 | 宽度 | 样式 |
|------|------|------|
| 事件ID | 110px | 代码风格标签 |
| 事件名称 | min-width: 150px | 加粗，展示中文名称 |
| 备注 | min-width: 180px | 次要文字色，无时 `—` |
| 推送文案 | min-width: 200px | 次要文字色，展示中文文案 |
| 引用算法数 | 110px，居中 | 小号绿色标签；0 时灰色「0」 |
| 操作 | 140px，居中，固定右侧 | 「编辑」「删除」

### 2.2 添加/编辑算法弹窗

**触发**：算法库 Tab「添加算法」按钮，或行操作「编辑」按钮。

| 属性 | 说明 |
|------|------|
| 类型 | 模态弹窗 |
| 宽度 | 720px |
| 关闭行为 | 点击遮罩不关闭，关闭时销毁内容 |

**区域 1：基础信息**
| 字段 | 控件 | 说明 |
|------|------|------|
| AlgorithmID | 文本输入框 | placeholder「如 4001」 |
| 算法名称 | 中文输入框 + 地球图标「多语言」按钮 | 打开多语言弹窗，16 语言 |
| 算法类型 | 单选按钮 | 设备 / 平台，默认设备 |
| 排序 | 数字输入 | 最小 0，宽度 100% |
| 图标 | 文本输入框 | placeholder「icon name 或 emoji」 |

**区域 2：能力配置**
- 8 项通用能力勾选框（Switch / Sensitivity / Schedule / DetectArea / SoundAlarm / AlarmRepeatCnt / CustomAudio / LightAlarm）
- 侦测类型子表（键值对动态行，最多 20 行）
- 能力选中状态通过表单对象管理

**区域 3：关联事件**
- 双面板穿梭框（左：可选事件 / 右：已选事件）
- 每行显示 eventId + 中文名称
- 点击切换

**区域 4：扩展属性**
- 多行文本输入框（4 行高度），选填

**底部按钮**：「取消」+「确认创建/确认保存」

### 2.3 事件编辑弹窗

| 属性 | 说明 |
|------|------|
| 类型 | 模态弹窗 |
| 宽度 | 560px |

| 字段 | 控件 | 说明 |
|------|------|------|

| 备注 | 文本输入框 | 选填 |
| 推送文案 | 中文输入框 + 地球图标「多语言」按钮 | 中文必填 |

### 2.4 算法能力详情页

**页面结构**：
- 顶部返回栏：返回按钮 + 算法名 + 能力数 +「关联能力」按钮
- 左栏模块侧栏：仅显示已关联能力涉及的模块（去重）
- 右栏能力表格：类型 / 名称 / 标识符 / 数据类型 / 数据定义 / 描述 / 模块 / 操作

**关联能力穿梭框**：
- 左侧：能力池可选能力，按模块分组展示（已关联的自动排除）
- 右侧：待导入能力列表
- 支持搜索过滤 + 模块折叠展开

**编辑能力参数弹窗**：
- 类型/名称/标识符：只读
- 数据定义：可编辑（支持全部数据类型：枚举/整数/布尔/字符串/数组/结构体）
- 服务类型能力支持编辑输入/输出参数

|------|------|

## 3. 状态说明

| 状态 | 触发条件 | 展示内容 |
|------|------|------|
| 正常态 | 列表有数据 | 表格正常展示 |
| 空态 | 列表无数据 / 搜索无结果 | 空态插图 + 快捷添加按钮 |
| 加载态 | 接口请求中 | 表格加载动画，弹窗内加载动画覆盖表单 |
| 错误态 | 接口异常 | 消息提示自动弹出（请求拦截器统一处理） |
| ID 冲突 | AlgorithmID/EventID 重复 | 错误消息提示，弹窗不关闭 |
| 引用拦截 | 删除时存在引用 | 警告消息提示引用数量，不执行删除 |

## 6. 交互规范

### 6.1 弹窗交互
- 创建模式标题为「添加算法/事件」，确认按钮为「确认创建」
- 编辑模式标题为「编辑算法/事件」，确认按钮为「确认保存」
- 点击遮罩不关闭弹窗
- 关闭弹窗时销毁内部内容，下次打开重新初始化
- 弹窗内表单提交时确认按钮进入加载态，防止重复提交

### 6.2 表格交互
- 能力标签最多显示 5 个，超出显示 `+N`（悬浮显示完整列表）
- 操作列固定在表格右侧
- 表格行支持点击跳转（物模型路由版：关联能力数可点击跳转详情页）

### 6.3 穿梭框交互
- 点击行切换选中状态
- 支持搜索过滤（匹配名称和ID）
- 左侧仅显示未关联的项
- 空态提示「暂无数据」

### 6.4 删除交互
- 所有删除操作需二次确认（确认对话框）
- 确认按钮为红色危险样式
- 有引用时拦截删除，弹出警告消息提示引用数量
