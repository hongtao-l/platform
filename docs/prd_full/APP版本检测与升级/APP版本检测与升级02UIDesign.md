## 一、页面结构

```
Me 页面（/me）
  └─ 「关于」菜单项 → /about
                        └─ 关于页面
                              └─ 「版本更新」按钮 → 手动检测 → 升级弹窗

App.vue（启动时）
  └─ 自动版本检测 → 有新版本 → 升级弹窗
```

### 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 关于页面 | `/about` | 新增页面，展示 App 信息 + 版本更新入口 + 法律链接 |
| 升级弹窗 | 全局组件 | 复用于自动检测和手动检测，居中弹出 |

## 二、布局详述

### 2.1 关于页面（/about）

参考现有 settings 页面风格（暗色主题 + 卡片式布局）。

#### 区域 1：页面头部

```
┌──────────────────────────────┐
│  ←  关于                      │
└──────────────────────────────┘
```

- 顶部导航栏，左侧返回箭头，标题「关于」
- 复用现有 settings/index.vue 的 `.page-header` 样式
- 背景色：`#0D1117`

#### 区域 2：App 信息区

```
┌──────────────────────────────┐
│       ┌────────┐             │
│       │ App    │             │
│       │ Logo   │  72×72      │
│       └────────┘             │
│      CareCam Pro             │
│      当前版本 v1.0.0          │
└──────────────────────────────┘
```

- 垂直居中布局
- Logo：圆角图标（可用现有 App 图标或 van-icon 占位），72×72px，圆角 16px
- 名称：白色，16px，font-weight 600
- 版本号：灰色（#888），13px，格式「当前版本 v1.0.0」
- 上下间距：Logo 上方 40px，名称与版本间距 8px，整体区域 padding 32px 0

#### 区域 3：功能菜单区

```
┌──────────────────────────────┐
│  🔄  版本更新          >     │
├──────────────────────────────┤
│  📋  用户协议          >     │
├──────────────────────────────┤
│  🔒  隐私政策          >     │
└──────────────────────────────┘
```

- 菜单列表样式，复用 Me 页面 `.menu-item` 样式
- 每项：左侧圆角 icon 容器（28×28）+ 标签文字 + 右侧箭头
- icon 容器背景色参考 Me 页面：
  - 版本更新：`#F0FDF4` / icon `#16A34A`
  - 用户协议：`#FFF7ED` / icon `#EA580C`
  - 隐私政策：`#F0F9FF` / icon `#0284C7`
- 点击「版本更新」→ 触发手动检测（loading + 接口请求）
- 点击「用户协议」/「隐私政策」→ 跳转外部链接

### 2.2 升级弹窗（全局组件）

参考现有 `ActivityPopup.vue` 的 `van-popup` 居中弹出模式。

#### 弹窗布局

```
┌──────────────────────────┐
│                     ✕    │
│      ┌──────────┐        │
│      │   🚀     │        │
│      │  图标    │ 64px   │
│      └──────────┘        │
│                          │
│     发现新版本 v1.2.0     │
│                          │
│     更新内容：            │
│     • 修复夜间模式白平衡   │
│     • 新增AI人形检测      │
│     • 优化P2P连接速度     │
│     ...（可滚动）         │
│                          │
│   ┌──────────────────┐   │
│   │   立即更新         │   │
│   └──────────────────┘   │
│      稍后提醒             │
└──────────────────────────┘
```

- 宽度：300px，圆角 16px，白色背景
- 可关闭（右上角 ✕），点击等价于「稍后提醒」
- 区域细分：

| 子区域 | 说明 |
|--------|------|
| 顶部图标 | App Logo 或 rocket/upgrade 类图标，64×64，圆角 12px |
| 标题 | 「发现新版本」+ 版本号（如 `v1.2.0`），16px，深色加粗，居中 |
| 更新日志 | 左侧标签「更新内容：」，下方文本列表，最多展示 5 行，超出可滚动（max-height 120px），13px，灰色 |
| 主按钮 | 「立即更新」，圆角 24px，蓝色（#1A73E8），全宽，高度 44px |
| 次按钮 | 「稍后提醒」，12px，灰色文字，居中，padding 12px |

#### 交互状态

| 状态 | 触发条件 | 表现 |
|------|----------|------|
| 正常态 | 有新版且今日未弹 | 展示完整弹窗 |
| 加载态 | 手动检测等待接口 | 「版本更新」按钮显示 loading spinner |
| 无新版本 | 接口返回已是最新 | Toast：「已是最新版本 ✓」 |
| 网络异常 | 手动检测超时 | Toast：「网络异常，请稍后重试」 |
| 下载链接为空 | 接口无 downloadUrl | 弹窗正常展示，但无「立即更新」按钮，底部提示「下载链接暂不可用」 |

## 三、组件清单

| 组件 | 类型 | 用途 | 来源 |
|------|------|------|------|
| 页面头部 | 自定义 | 关于页顶部导航 | 复用 settings 页 `.page-header` |
| App 信息区 | 自定义 | Logo + 名称 + 版本号 | 新增 |
| 菜单列表 | 自定义 | 版本更新/用户协议/隐私政策 | 复用 Me 页 `.menu-item` |
| 升级弹窗 | `van-popup` | 新版本升级提示 | 参考 ActivityPopup.vue |
| Toast | `van-toast` / `showToast` | 操作反馈 | Vant 内置 |
| Loading | `van-loading` | 手动检测加载态 | Vant 内置 |
