## 一、页面结构（信息架构）

```
首页设备列表（/home）
  └── NVR 设备卡片（1 张，展示通道数）
        └── NVR 通道列表页（/nvr/:deviceId）【新增】
              ├── 未绑定通道 → 「开通云存」→ 服务商城（云存储 Tab，自动选中该 NVR）
              └── 已绑定通道 → 展示到期时间 + 「解绑」

我的 → 服务商城（/store?tab=cloud）
  └── 开通设备切换到 NVR → 套餐自动切换为 NVR 按通道数分档套餐
        └── 确认订单（弹窗内选择绑定通道）→ 支付

我的 → 我的服务 → NVR 云存套餐 → 绑定通道页（/my-services/bind-channel）【补绑/解绑/重绑】
```

**导航路径关系**：
- `首页 NVR 卡片` → `NVR 通道列表页`（设备视角）
- `服务商城` → `确认订单弹窗`（购买时绑定通道）
- `我的服务` → `绑定通道页`（补绑/解绑/重绑，套餐视角）

## 二、布局详述

### 页面1：服务商城「云存储」— NVR 套餐筛选（修改 store/index.vue）

**定位**：复用现有服务商城页面，仅在「开通设备」选中 NVR 设备时，套餐内容切换。

| 区域 | 位置/尺寸 | 包含元素 | 交互行为 |
|------|-----------|----------|----------|
| 顶部导航 | 固定顶部 | 返回箭头 + 标题「服务商城」 | 返回上一页 |
| 服务 Tab | 顶部导航下 | 云存储 / AI智能服务 / 离线监测 / 去广告 / 流量充值 | 切换服务类型 |
| 开通设备栏 | Tab 下 | 视频图标 + 「开通设备」标签 + 当前设备名 + 箭头 | 点击弹底部设备选择弹窗 |
| 套餐卡片区 | 设备栏下，横向滚动 | NVR 套餐卡片（1路/4路/8路/16路） | 点击选中，高亮边框 |
| 支付方式 | 套餐下方 | 微信支付 / 支付宝 | 单选 |
| 套餐详情 | 支付下方 | 当前选中套餐的「包含内容」列表 | 随选中套餐联动 |
| 底部购买栏 | 固定底部 | 协议勾选 + 「立即开通 ¥XX/月」按钮 | NVR：点击弹出「确认订单」弹窗（含通道多选）；IPC 单设备直接购买 |

**NVR 套餐卡片（每张）**：
- 顶部运营标签（最划算 / 热门，可选）
- 档位名称：`4路`（大字）
- 价格：`¥XX` + `/月`
- 权益列表：`支持 4 个通道`、`15天事件录像`、`运动人形侦测` 等
- 选中态：主色边框 + 浅色背景（与现有 IPC 套餐一致）

**设备选择弹窗（NVR 购买时）**：单选一台 NVR 设备。

**确认订单弹窗（NVR 购买时，底部弹出，高约 65%）**：
- 顶部：套餐名 + 价格
- 支付方式（微信 / 支付宝）
- 「绑定通道」区：该 NVR 的通道列表多选，上限为档位支持通道数；离线通道置灰不可选
- 底部：「确认支付 ¥XX/月」按钮

### 页面2：绑定通道页（新增，复用 bind.vue 模式）

**定位**：套餐视角的通道绑定管理（补绑/解绑/重绑）。购买时已在确认订单完成首次绑定，此处从「我的服务」进入，用于后续调整。

| 区域 | 位置/尺寸 | 包含元素 | 交互行为 |
|------|-----------|----------|----------|
| 顶部导航 | 固定顶部 | 返回箭头 + 标题「绑定通道」 | 返回 |
| 套餐摘要卡片 | 顶部下 | 套餐名「NVR云存 4路」 + 「多通道」标签 + 大数字统计「已绑 X / N 路」 | 无，纯展示 |
| 已绑定通道 | 摘要卡下 | 通道列表：通道图标 + 通道名/编号 + 「已绑定」标签 + 「解绑」按钮 | 点解绑 → 确认弹窗 → 解绑 |
| 添加绑定按钮 | 已绑定列表下 | 虚线框 + 加号 + 「添加绑定通道」 | 点击弹底部多选弹窗 |
| 提示文字 | 底部 | 「后续查看/管理绑定通道请前往【我的】→【我的服务】」 | 无 |

**多选弹窗（底部弹出，高约 60%）**：
- 标题「选择通道」+ 右上「确定」
- 通道列表（仅未绑定通道）：每行 = 通道图标 + 通道号（CH1）+ 通道名称 + 在线状态
- 已绑定通道置灰/过滤不展示
- 选中数量受「剩余额度」限制，达上限时其余置灰
- 点「确定」完成绑定

**解绑交互**：
- 已绑定通道行右侧「解绑」文字按钮
- 点击 → `van-dialog` 确认弹窗：「解绑通道 CH1 后，该通道云存将停止，确定解绑？」→「取消 / 确定」
- 确定后：释放额度，该通道回到未绑定，统计数字即时更新

### 页面3：NVR 通道列表页（新增）

**定位**：设备视角，从首页 NVR 卡片进入，查看各通道云存状态并操作。

| 区域 | 位置/尺寸 | 包含元素 | 交互行为 |
|------|-----------|----------|----------|
| 顶部导航 | 固定顶部 | 返回箭头 + 标题「{NVR 名称}」+ 右侧设置图标 | 返回 / 进设备设置 |
| NVR 摘要卡片 | 顶部下 | NVR 图标 + 名称 + 「8路」标签 + 在线状态 | 无，纯展示 |
| 通道列表 | 摘要下 | 通道卡片列表（见下） | 点击通道卡片进入对应操作 |

**通道卡片（每行）**：
- 左侧：通道图标（摄像机）+ 通道号 `CH1` + 通道名称
- 右侧状态区：
  - 未绑定：`开通云存` 主色按钮 → 跳服务商城（自动选中该 NVR）
  - 已绑定生效中：绿色标签「云存生效中」+ 到期时间
  - 即将到期：橙色标签「X天后到期」
  - 已到期：红色标签「已到期」
- 已绑定通道：提供「解绑」入口（跳绑定通道页或直接弹确认）

**定位**：与 IPC 卡片同层级，差异在图标、通道数展示与点击跳转。

| 区域 | 包含元素 | 差异说明 |

| 点击卡片 | — | 跳 NVR 通道列表页（而非直播页） |

## 三、状态说明

### 页面1：服务商城

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 正常态（IPC） | 当前设备为 IPC | 展示 Basic/Pro/Super Pro 套餐 |
| 正常态（NVR） | 当前设备为 NVR | 展示 NVR 按通道数分档套餐 |
| 空态 | 无可用设备 | 设备栏提示「点击选择」，套餐仍展示 |
| 加载态 | 套餐/设备数据加载中 | 骨架屏或 loading |
| 错误态 | 套餐加载失败 | Toast「加载失败」+ 下拉重试 |

### 页面2：绑定通道页

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 正常态 | 有套餐、有可用通道 | 摘要 + 已绑定列表 + 添加按钮 |
| 空态（未绑定任何通道） | 套餐已购但未绑定 | 摘要 + 空态提示「暂未绑定通道」+ 添加按钮 |
| 满额态 | 已绑定数 = 支持通道数 | 隐藏/禁用「添加绑定通道」按钮 |
| 无可用通道 | NVR 无未绑定通道 | 添加弹窗空态「暂无可绑定通道」 |
| 错误态 | 套餐/通道数据加载失败 | 错误提示 + 重试 |

### 页面3：NVR 通道列表页

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 正常态 | NVR 有通道 | 通道列表，各通道独立云存状态 |
| 空态 | NVR 未接入摄像机 | 空态「暂未接入摄像机」 |
| 加载态 | 通道数据加载中 | 骨架屏 |
| 错误态 | 通道加载失败 | 错误提示 + 重试 |

### 页面4：NVR 设备卡片

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 在线 | NVR 在线 | 绿色「在线」徽标 |
| 离线 | NVR 离线 | 灰色「离线」徽标 |
| 已分享 | 设备被分享 | 「已分享」标签 |

## 五、设计要点

1. **复用优先**：服务商城、绑定流程复用现有 store/index.vue 与 bind.vue 的交互与视觉，NVR 仅替换「设备」为「通道」。
2. **一致性**：颜色、圆角（$radius-lg/md/sm）、间距、字号沿用项目 SCSS 设计令牌（$bg-page、$bg-card、$primary-color、$shadow-card 等）。
3. **通道的「设备化」呈现**：通道在 UI 上按「子设备」呈现（图标 + 编号 + 名称 + 状态），复用设备列表的视觉语言，降低理解成本。
4. **购买即绑定**：购买确认订单中直接完成通道绑定，减少「购买后还需单独绑定」的步骤；后续解绑/重绑/补绑在「我的服务」进行。
5. **解绑安全**：解绑操作需二次确认（van-dialog），避免误操作导致通道云存中断。
