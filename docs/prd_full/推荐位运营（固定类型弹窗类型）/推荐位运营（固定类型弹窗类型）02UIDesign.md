## 一、页面结构

### 1.1 整体结构

```
推荐位运营页面
├── 顶部 ops-tabs（商城位 / 推荐位 / 活动位）     ← 不变
├── 左侧边栏（应用 → 推荐位树）                    ← 不变
└── 右侧内容区
    └── 推荐位选中时：
        ├── 推荐类型切换 Tab（弹窗类型 / 固定类型）  ← 新增
        ├── 弹窗类型面板（现有：漏斗 Tab + 策略 Tab） ← 不变
        └── 固定类型面板（新增：策略列表 + 抽屉）    ← 新增
```

### 1.2 页面清单

| 页面/区域 | 说明 | 改动类型 |
|-----------|------|----------|
| 推荐位右侧面板 — 类型切换 | 弹窗类型 / 固定类型 Tab 切换 | 新增 |
| 固定类型策略列表 | 表格展示固定类型策略 | 新增 |
| 固定类型策略抽屉 | 单页表单：基础信息 + 套餐配置 + 投放配置 | 新增 |
| 套餐选择抽屉 | 复用现有，从套餐库选择套餐 | 复用 |
| 弹窗类型所有界面 | 漏斗 Tab + 策略 Tab + 抽屉 | 不变 |

## 二、布局详述

### 2.1 类型切换 Tab

```
┌──────────────────────────────────────────────────────────┐
│  [ 弹窗类型 ]    [ 固定类型 ]                               │
│  ───────────                                                │
│                                                            │
│  （下方为对应类型的内容区）                                    │
└──────────────────────────────────────────────────────────┘
```

- 位置：右侧内容区顶部，在「{推荐位名称} · XX」标题上方
- 样式：与现有 `ops-tabs` 风格一致（下划线指示激活项）
- 默认选中「弹窗类型」
- 切换时若固定类型策略抽屉未保存，弹出确认提示
- 固定类型选中时，隐藏「推荐位套餐漏斗」Tab（只显示策略列表）

**交互**：

| 操作 | 结果 |
|------|------|
| 点击「弹窗类型」 | 展示现有漏斗 Tab + 策略 Tab |
| 点击「固定类型」 | 隐藏漏斗 Tab，展示固定类型策略列表 |

### 2.2 固定类型 — 策略列表

```
┌──────────────────────────────────────────────────────────┐
│  首页推荐位 · 固定类型策略                                   │
│                                                            │
│  ┌ 策略列表 ──────────────────────────────────────────┐  │
│  │                                         [＋ 添加策略] │  │
│  │──────────────────────────────────────────────────────│  │
│  │ 策略名称 │ 位置编码 │ 套餐数 │ 冷却 │ 投放区域 │ 分群 │备注│操作│
│  │──────────┼──────────┼────────┼──────┼──────────┼──────┼────┼───│
│  │ 首页底部  │ home_    │   3    │  2   │  国内    │ 新用户│ — │编辑│
│  │ 推荐策略  │ bottom   │  个   │ 小时 │          │      │   │删除│
│  │──────────┼──────────┼────────┼──────┼──────────┼──────┼────┼───│
│  │ 海外首页  │ home_    │   2    │  4   │  海外    │ 全部  │ — │编辑│
│  │ 推荐      │ bottom   │  个   │ 小时 │          │      │   │删除│
│  └──────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- 标题格式：`{推荐位名称} · 固定类型策略`
- 列表为空时展示空态：「暂无固定类型策略，点击上方按钮添加」
- 表格列定义：

| 列名 | 宽度 | 说明 |
|------|------|------|
| 策略名称 | min-width: 160 | 粗体展示 |
| 位置编码 | width: 120 | 如 `home_bottom`，tag 样式 |
| 套餐数量 | width: 80 | 「3 个」 |
| 冷却时间 | width: 90 | 「2 小时」 |
| 投放区域 | width: 120 | tag 列表 |
| 用户分群 | width: 150 | tag 列表，无分群显示「全部用户」 |
| 备注 | width: 120 | 超长省略 + tooltip |
| 操作 | width: 140 | 编辑 / 删除 |

### 2.3 固定类型 — 策略抽屉（新增/编辑）

整体为单页表单（不分步），分三个区域从上到下排列。

#### 2.3.1 抽屉整体

```
┌─────────────────────────────────────┐
│  添加固定类型策略              ✕    │
│─────────────────────────────────────│
│                                     │
│  ▎ 基础信息                         │
│  ┌─────────────────────────────┐   │
│  │ 策略名称   [______________] │   │
│  │ 位置编码   [home_bottom ▾]  │   │
│  │ 备注       [______________] │   │
│  │            [______________] │   │
│  └─────────────────────────────┘   │
│                                     │
│  ▎ 套餐配置                         │
│  ┌─────────────────────────────┐   │
│  │  #1  REC_001  7天事件云存储  ¥6.90  │  ↑ ↓ ✕ │
│  │  #2  REC_003  AI智能检测月卡 ¥9.90  │  ↑ ↓ ✕ │
│  │  #3  REC_004  全家桶年度套餐 ¥199.00│  ↑ ↓ ✕ │
│  │                             │   │
│  │         [＋ 添加套餐]        │   │  ← 最多5个时隐藏
│  └─────────────────────────────┘   │
│                                     │
│  ▎ 投放配置                         │
│  ┌─────────────────────────────┐   │
│  │ 冷却时间    [2] 小时         │   │
│  │ 投放区域    ☑ 国内  ☐ 海外  │   │

│                                     │
│            [取消]  [确定]            │
└─────────────────────────────────────┘
```

- 抽屉尺寸：`560px`（与现有漏斗抽屉一致，不需要 720px 的大抽屉）
- 标题：新增模式「添加固定类型策略」，编辑模式「编辑固定类型策略」
- 表单 label-position: `top`

#### 2.3.2 区域一：基础信息

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 策略名称 | `el-input` | 是 | placeholder: 「请输入策略名称」，maxlength 50 |
| 位置编码 | `el-select` | 是 | 下拉枚举值，当前仅 `home_bottom`（首页底部），placeholder: 「请选择展示位置」 |
| 备注 | `el-input type="textarea"` | 否 | rows: 3, placeholder: 「请输入备注信息」 |

#### 2.3.3 区域二：套餐配置

- 套餐列表展示为有序列表（#1 ~ #5）
- 每个套餐项一行：

```
┌─────────────────────────────────────────────────────────┐
│  #1  [REC_001]  7天事件云存储基础版          ¥6.90      │
│      ─────────────────────────────────────              │
│      云存储套餐                                          │
│                                          [↑] [↓] [✕]   │
└─────────────────────────────────────────────────────────┘
```

每项元素：
| 元素 | 说明 |
|------|------|
| 序号 `#N` | 粗体，14px |
| 套餐编码 | 灰色 tag 样式 |
| 套餐名称 | 主文字 |
| 分类标签 | 如「云存储套餐」 |
| 价格 | 右侧，主色 |
| 操作按钮组 | 上移 ↑ / 下移 ↓ / 移除 ✕，紧凑排列在右侧 |

**排序规则**：
- 首项「上移」置灰
- 末项「下移」置灰
- 仅 1 个套餐时，「移除」置灰（至少保留 1 个）

**「添加套餐」按钮**：
- 样式：dashed 边框，居中，「＋」图标 + 「添加套餐」文字
- 点击打开套餐选择抽屉（复用现有 `pkgSelectVisible` 抽屉）
- 列表满 5 个时隐藏此按钮

**添加套餐确认后**：新套餐追加到列表末尾。

#### 2.3.4 区域三：投放配置

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 冷却时间 | `el-input-number` | 是 | min: 1, max: 720, 后跟「小时」文字，placeholder: 「如：2」 |
| 投放区域 | `el-checkbox` 组 | 是 | 国内 / 海外，至少选一项 |
| 用户分群 | `el-select` 多选 | 否 | 复用现有人群选择器，不选 = 全部用户 |

描述文字在冷却时间下方显示：「用户关闭推荐位后，需等待 N 小时才会再次展示」

#### 2.3.5 编辑模式

- 预填现有策略数据
- 标题变为「编辑固定类型策略」
- 其余交互与新增模式一致

## 三、状态说明

### 3.1 策略列表

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 正常态 | 有 ≥1 条策略 | 表格展示策略列表 |
| 空态 | 无策略 | 空态插画 + 「暂无固定类型策略，点击上方按钮添加」 |
| 加载态 | 数据请求中 | 表格 skeleton / loading 遮罩 |

### 3.2 策略抽屉

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 新增模式 | 点击「添加策略」 | 空白表单，标题「添加固定类型策略」 |
| 编辑模式 | 点击「编辑」 | 预填数据表单，标题「编辑固定类型策略」 |
| 校验失败 | 保存时字段不合法 | 对应字段红色边框 + 错误提示，Toast 首个错误 |
| 提交中 | 点击确定后等待 | 确定按钮 loading |

### 3.3 套餐列表（抽屉内）

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 正常态 | 1~4 个套餐 | 有序列表 + 排序按钮 + 添加按钮 |
| 满额态 | 5 个套餐 | 「添加套餐」按钮隐藏 |
| 单项态 | 仅 1 个套餐 | 上移/下移/移除均置灰 |
| 空态 | 0 个套餐（仅新建未添加时） | 「暂未添加套餐」+ 添加按钮 |

## 四、交互说明

### 4.1 类型切换

```
点击「固定类型」Tab
  ├── 弹窗类型抽屉未保存 → 弹出确认提示 → 确认 → 切换
  └── 无未保存内容 → 直接切换
```

### 4.2 套餐排序

```
点击「↑」上移
  → 当前项与上一项交换位置
  → 序号重新排列
  → 首项「↑」始终置灰

点击「↓」下移
  → 当前项与下一项交换位置
  → 序号重新排列
  → 末项「↓」始终置灰
```

### 4.3 套餐移除

```
点击「✕」
  → 列表仅剩 1 项：按钮置灰，不响应
  → 列表 ≥2 项：直接移除，后续项序号上移
```

### 4.4 保存校验

校验顺序（遇到第一个错误即停止并 Toast）：
1. 策略名称为空 → 「请输入策略名称」
2. 位置编码未选 → 「请选择展示位置」
3. 套餐列表为空 → 「请至少添加 1 个套餐」
4. 冷却时间 ≤ 0 → 「冷却时间需为正整数」
5. 投放区域未选 → 「请选择投放区域」
