## 一、页面结构

```
首页 (/home)
  └─ 设备卡片 → AI按钮
       ├─ 未开通Agent → Agent市场 (/agent-market)
       │    ├─ Agent列表
       │    └─ Agent落地页 (/agent-market/:agentId)
       │         └─ 购买 → 支付 → 回到AI首页
       └─ 已开通Agent → AI首页 (/ai)  ← 改造现有页面
            ├─ AI消息 (/ai/message)
            ├─ AI日报 (/ai/daily)
            ├─ AI搜索 (/ai/search)
            └─ 我的Agent (/my-agent)  ← 新增
                 ├─ 查看已购Agent
                 ├─ 续费
                 └─ 选购新Agent → Agent市场
```

**Agent入口路径：**
- 设备已开通Agent → 设备卡片AI按钮 → `/ai`（显示当前Agent信息 + 功能入口）
- 设备未开通Agent → 设备卡片AI按钮 → `/agent-market`（Agent市场）
- `/ai` 页面内 → 「我的Agent」入口 → `/my-agent`

#### 区域详述

- 位置: 头部下方

- 布局: 纵向排列，间距12px

| 空态 | 后台未上架任何Agent | 空态占位：「暂无可用Agent」 |
| 加载态 | 请求Agent列表 | 骨架屏（3个卡片占位） |

```
│                              │
│  ┌────────────────────────┐  │

│                              │
└──────────────────────────────┘
```

#### 区域详述

**区域1: 当前Agent状态卡片**
- 白底卡片、16px圆角、阴影

- 右侧: 状态标签（生效中=绿色/即将到期=橙色/已到期=红色）
- 底部操作按钮（仅在生效中时显示续费）:
  - 续费（距到期≤7天显示）: 主色按钮
  - 选购新Agent: 次要按钮（边框样式）

**区域2: 历史购买记录**
- 标题「历史购买」: 14px/700
- 已过期的Agent卡片，半透明/灰色调
- 每条显示: 名称 + 使用时间段 + 「再次购买」按钮
- 空态: 「暂无购买记录」

#### 状态说明

| 状态 | 触发条件 | 展示 |
|------|----------|------|
| 生效中 | 当前设备有生效Agent | 正常状态卡片 + 「续费」按钮（距到期≤7天） |
| 即将到期 | 距到期≤7天 | 状态标签变橙色 + 续费按钮高亮 |
| 已到期 | Agent已过期 | 状态标签变红 + 续费按钮消失 + 「选购新Agent」 |
| 无Agent | 设备从未购买 | 空态引导：「去Agent市场选购」→ 跳转Agent市场 |
| 加载态 | 请求Agent数据 | 骨架屏 |

### 2.4 AI首页改造 (`/ai/index.vue`)

#### 改动要点

1. **标题**: 「全能AI配置」→「{{ agentName }}」（动态显示当前Agent名）
2. **已开通态**: 与现有逻辑一致，增加Agent名称 + 到期日期展示
3. **未开通态**: 改为跳转到Agent市场（`/agent-market`）
4. **新增入口**: 在已开通态底部增加「我的Agent」入口卡片或按钮


#### 与现有页面的差异

| 项目 | 现有 | 改造后 |
|------|------|--------|

### 2.5 AI日报页改造 (`/ai/daily.vue`)

#### 改动要点

1. 日报内容由当前Agent的`日报聚合提示词`生成
2. 关注事件分类由Agent专属`focus_list`决定（不再是「人员/宠物/告警/其他」四类）
3. 设备筛选仅显示已开通该Agent的设备
4. UI结构不变，仅数据来源变化

---

### 2.6 AI消息页改造 (`/ai/message.vue`)

#### 改动要点

1. 分类Tab由Agent专属`focus_list`决定（宠物Agent: 进食/排泄/异常/玩耍/睡眠）
2. 消息推送设置面板，开关按Agent专属分类展示
3. UI结构不变，仅分类维度变化

### 2.7 首页设备卡片AI按钮 (`/home/index.vue`)

#### 改动要点

设备卡片底部的AI按钮逻辑调整：

```javascript
// 现有逻辑
if (isDeviceActivated(device.name)) → /ai
else → /ai?show=activate

// 改造后
if (deviceHasAgent(device.name)) → /ai
else → /agent-market
```
