## 一、页面结构

本需求仅改动「智能体配置」页（`/agent/:id` 配置 Tab）的 3 个区块，页面整体框架（左侧导航锚点 + 中间表单 + 右侧预览）不变。

```
智能体配置页 (/agent/:id)
├── 左侧导航锚点（① 抓图配置 / ② 事件识别 / ③ AI 搜索 / ④ 阶段总结 / 高级设置）
├── 中间表单区（config-form，可滚动）
│   ├── ① 抓图配置（sec-capture）
│   │   ├── 抓图模式（mode-selector：事件触发 / 定时抓图 / 混合模式 三张卡片）
│   │   ├── 触发事件类型（【新增】仅 事件/混合 模式显示）
│   │   │   ├── 全部（el-radio，默认）→ 提示文案
│   │   │   └── 指定（el-radio）→ 事件多选复选框 pills
│   │   ├── 定时抓图间隔（slider + input-number）
│   │   └── 每日抓图上限（input-number）
│   ├── ② 事件识别（sec-recognition）
│   │   ├── 事件配置（【新增】el-radio-group：指定事件 / 自定义事件）
│   │   │   ├── 指定事件 → 事件标签区 + [选择事件] 按钮（【新增】）
│   │   │   └── 自定义事件 → 引导说明文案
│   │   ├── 温度（slider）
│   │   ├── 系统提示词（textarea + 调试）
│   │   └── 输出格式提示词（textarea + 调试）
│   │   （【移除】模型选择）
│   ├── ③ AI 搜索（sec-search，不变）
│   ├── ④ 阶段总结（sec-summary）
│   │   ├── 总结周期（【改造】固定「日总结」tag + 备注）
│   │   ├── 总结提示词（textarea + 调试）
│   │   └── 输出格式提示词（textarea + 调试）
│   │   （【移除】模型选择、周期下拉、Cron 配置）
│   └── 高级设置（sec-advanced，不变）
├── 右侧预览区（不变）
└── 事件选择抽屉（【新增】el-drawer 640px，事件多选）
```

## 二、页面布局详述

### 2.1 ① 抓图配置 — 触发事件类型（新增）

**位置**：抓图模式卡片下方，`v-if` 抓图模式为「事件触发」或「混合模式」时显示。

**整体布局**：
```
┌────────────────────────────────────────────────────┐
│  抓图模式                                           │
│  ┌────────┐ ┌────────┐ ┌────────┐                  │
│  │ ⚡     │ │ ⏱     │ │ 🔀     │                  │
│  │事件触发│ │定时抓图│ │混合模式│                  │
│  └────────┘ └────────┘ └────────┘                  │
│                                                     │
│  触发事件类型                                       │
│  (●) 全部   ( ) 指定                                │  ← el-radio-group
│  ┌─────────────────────────────────────────────┐   │
│  │ 设备上报的全部事件均触发抓图                 │   │  ← 全部：提示文案
│  └─────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────┘
```

**「指定」选中后**：
```
│  触发事件类型                                       │
│  ( ) 全部   (●) 指定                                │
│  ┌─────────────────────────────────────────────┐   │
│  │ [✓移动侦测] [✓声音侦测] [人形检测] [✓宠物检测]│   │  ← checkbox-pills
│  │ [车辆检测] [门铃呼叫] [烟雾告警] [温度告警]   │   │
│  └─────────────────────────────────────────────┘   │
```

**元素说明**：
| 元素 | 组件 | 说明 |
|------|------|------|
| 触发事件类型 | `el-radio-group` + `el-radio` | 两个 radio「全部」「指定」，`value` 分别为 `all` / `specified` |
| 事件多选 | `el-checkbox`（`size="small"`） | 8 个事件，用 `.checkbox-pills` + `.event-pills` 容器流式排列 |
| 全部提示 | `<p class="toggle-desc">` | 「设备上报的全部事件均触发抓图」 |

**事件选项**（8 项，设备能力类事件）：
移动侦测、声音侦测、人形检测、宠物检测、车辆检测、门铃呼叫、烟雾告警、温度告警

### 2.2 ② 事件识别 — 事件配置（新增）

**位置**：事件识别模块开启后，`enableRecognition` 开关下的第一个 field-group。

**整体布局**：
```
┌────────────────────────────────────────────────────┐
│  ② 事件识别                    [已开启] [开关]     │
│                                                     │
│  事件配置                                           │
│  (●) 指定事件   ( ) 自定义事件                      │  ← el-radio-group
│                                                     │
│  指定事件                                           │
│  ┌─────────────────────────────────────────────┐   │
│  │ [宠物进食 ×] [包裹送达 ×] [家人出入 ×]       │   │  ← 已选事件标签
│  │ 未选择事件（空态）                           │   │
│  │                                     [选择事件]│   │  ← 打开抽屉
│  └─────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────┘
```

**「自定义事件」选中后**：
```
│  事件配置                                           │
│  ( ) 指定事件   (●) 自定义事件                      │
│  ┌─────────────────────────────────────────────┐   │
│  │ 自定义事件由终端用户自行定义，平台不提供事件  │   │  ← 引导说明
│  │ 配置；终端用户可在 APP 中根据实际需求创建自   │   │
│  │ 定义事件。                                   │   │
│  └─────────────────────────────────────────────┘   │
```

**元素说明**：
| 元素 | 组件 | 说明 |
|------|------|------|
| 事件配置 | `el-radio-group` + `el-radio` | 「指定事件」`specified` /「自定义事件」`custom` |
| 指定事件区 | `.event-select-box` | 容器内：左侧 `.event-tags` 标签区 + 右侧 [选择事件] 按钮 |
| 已选事件标签 | `el-tag`（`size="small"` `closable`） | 每个已选事件一个标签，点 × 删除 |
| 未选空态 | `<span class="event-empty">` | 「未选择事件」 |
| 自定义引导 | `.custom-event-hint` + `<p class="toggle-desc">` | 说明文案 |

**移除项**：事件识别模块原「模型选择」下拉已移除。

### 2.3 事件选择抽屉（新增）

**触发**：点击「选择事件」按钮。

**实现**：`el-drawer`，`direction="rtl"`，`size="640px"`，`title="选择事件"`，`close-on-click-modal="false"`。

```
┌────────────────────────────────────────────────┐
│  选择事件                                [×]   │
├────────────────────────────────────────────────┤
│  ┌────┬──────────────────┬──────────────┐      │
│  │ ☐  │  事件名称        │  事件 ID     │      │
│  ├────┼──────────────────┼──────────────┤      │
│  │ ☑  │  宠物进食        │  500001      │      │
│  │ ☐  │  宠物排泄        │  500002      │      │
│  │ ☑  │  呕吐/异常       │  500003      │      │
│  │    │  ...             │  ...         │      │
│  │ ☐  │  多人聚集        │  600008      │      │
│  └────┴──────────────────┴──────────────┘      │
├────────────────────────────────────────────────┤
│                             [取消]  [保存]     │
└────────────────────────────────────────────────┘
```

**表格列定义**：
| 列名 | 组件 | 宽度 | 说明 |
|------|------|------|------|
| 选择 | `el-table-column type="selection"` | 44 | 多选框 |
| 事件名称 | `el-table-column` | min-width:140 | 事件名称 |
| 事件ID | `el-table-column` | min-width:120 | 事件唯一标识（原「事件标识」已改名为「事件ID」） |

**交互规则**：
1. 打开抽屉时，已选事件（`form.recogEvents`）预勾选
2. 勾选/取消勾选实时更新临时选中集合
3. 点击「保存」→ 写回表单，关闭抽屉，标签区刷新
4. 点击「取消」→ 丢弃本次改动，关闭抽屉
5. 已移除「所属看护」列（原 4 列 → 现 3 列）

### 2.4 ④ 阶段总结 — 总结周期（改造）

**位置**：阶段总结模块开启后，第一个 field-group。

**整体布局**：
```
┌────────────────────────────────────────────────────┐
│  ④ 阶段总结                    [已开启] [开关]     │
│                                                     │
│  总结周期                                           │
│  [日总结]                                          │  ← 固定 tag，不可编辑

│                                                     │
│  总结提示词          [调试 ▸]                       │
│  ┌─────────────────────────────────────────────┐   │
│  │ 根据${period}内的事件记录，总结情况...       │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  输出格式提示词      [调试 ▸]                       │
│  ┌─────────────────────────────────────────────┐   │
│  │ 定义阶段总结的输出JSON格式...                │   │
│  └─────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────┘
```

**元素说明**：
| 元素 | 组件 | 说明 |
|------|------|------|
| 总结周期 | `.cycle-fixed` + `el-tag`（`type="info"` `size="small"`） | 固定展示「日总结」，无交互 |
| 备注 | `<p class="toggle-desc">` | 「用户手动生成，单日最多生成3次，历史未生成总结的日期，仅支持生成1次」 |
| 总结提示词 | `el-input textarea` + 调试按钮 | 保留 |
| 输出格式提示词 | `el-input textarea` + 调试按钮 | 保留 |

**移除项**：阶段总结模块原「模型选择」「总结周期下拉」「Cron 表达式」已移除。

## 三、状态说明

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 触发事件类型-全部 | 抓图模式为事件/混合，默认 | radio 选中「全部」+ 提示文案 |
| 触发事件类型-指定 | 选中「指定」 | 8 个事件复选框 pills |
| 事件配置-指定事件 | 默认 | 已选事件标签 + [选择事件] 按钮 |
| 事件配置-指定空态 | 未选择任何事件 | 「未选择事件」占位 |
| 事件配置-自定义 | 选中「自定义事件」 | 引导说明文案 |
| 事件抽屉-正常态 | 打开抽屉 | 事件清单表格，已选预勾选 |
| 事件抽屉-空态 | 事件清单为空 | 空态占位「暂无可用事件」 |
| 阶段总结-周期 | 阶段总结已开启 | 固定「日总结」tag + 备注 |
| 抓图模式-定时 | 抓图模式切到定时 | 触发事件类型区隐藏 |
| 模块关闭态 | 事件识别/阶段总结开关关闭 | 展示 `.step-disabled-hint` 引导 |

## 四、关键交互说明

1. **触发事件类型切换**：点「全部」↔「指定」，复选框区显隐切换；切回「全部」时保留已勾选事件（不丢失）
2. **抓图模式联动**：抓图模式为「定时抓图」时，触发事件类型区整体隐藏；切回「事件/混合」时还原
3. **打开事件选择抽屉**：点击「选择事件」→ 抽屉打开，已选事件预勾选
4. **抽屉保存/取消**：保存写回表单标签区；取消丢弃改动
5. **删除已选事件**：点击事件标签的 × 直接移除，无需进抽屉
6. **事件配置切换**：点「指定事件」↔「自定义事件」，下方区域对应切换
7. **总结周期**：纯展示，不可编辑

## 六、样式要点

- 复用现有 `.field-group`、`.field-label`、`.toggle-desc`、`.param-row`、`.slider-val` 等 class
- 新增 `.event-pills`（checkbox 流式排列，`flex-wrap` + `gap`）
- 新增 `.event-select-box`（`flex` 两端对齐：左侧标签区 + 右侧按钮）
- 新增 `.event-tags`（标签流式排列，标签间 `gap`）
- 新增 `.event-empty`（空态灰字）
- 新增 `.custom-event-hint`（引导说明容器，`bg-card` 浅底 + 圆角 + 内边距）
- 新增 `.cycle-fixed`（固定周期标签容器）
- 抽屉覆盖样式使用**非 scoped** `<style lang="scss">` 块
- 抽屉 body `padding-top: 20px`
- 元素间保持合理间距，不顶容器边缘（遵循 UI 自检 SOP）
