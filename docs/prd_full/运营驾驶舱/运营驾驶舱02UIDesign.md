## 一、整体风格定位

### 1.1 视觉关键词

**深空科技 · 数据指挥中心 · 沉浸式看板**

不是传统 B 端后台的白色表单页，而是一个**暗色主题、高信息密度、强科技感的数据驾驶舱**。参照 NASA 任务控制中心、科幻电影 HUD 界面、量化交易终端的美学。

### 1.2 配色方案

| Token | 色值 | 用途 |
|-------|------|------|
| 主背景 | `#0A0E14` | 页面底色，极深蓝黑 |
| 面板背景 | `#12171F` | 卡片/面板底色，比主背景略亮 |
| 面板边框 | `rgba(255,255,255,0.06)` | 面板 1px 描边 |
| 高亮边框 | `rgba(0,242,255,0.15)` | 悬停/活跃面板发光边框 |
| 数据主色（青） | `#00F2FF` | 主要数据高亮、图表折线、强调数字 |
| 数据辅色（蓝） | `#3E63DD` | 次要数据、柱状图、区域二 |
| 数据辅色（紫） | `#7000FF` | 第三数据色、特殊标记 |
| 成功色 | `#00E676` | 正增长箭头 ↑、转化率达成 |
| 警告色 | `#FFB74D` | 负增长箭头 ↓、需关注指标 |

| 光晕色 | `rgba(0,242,255,0.08)` | 面板内发光 |

### 布局规则

- **设计宽度**：1440px（标准桌面宽屏），内容区 1360px，左右各 40px 留白
- **栅格**：12 列，列宽 100px，列间距 20px
- **顶部栏**：固定高度 56px，左侧 logo+标题，右侧刷新按钮 + 更新时间
- **筛选栏**：高度 48px，胶囊式按钮组
- **内容区**：两栏为主（左 8 列 / 右 4 列），局部可三栏等分

### 面板层级

每块内容放在独立「面板」内：
- 面板背景 `#12171F`，1px 边框 `rgba(255,255,255,0.06)`，圆角 12px
- 面板之间间距 20px
- 面板标题在面板内左上角，灰色小字大写
- 面板内容区内边距 24px

## 四、交互动效详述

### 4.1 页面入场动效

| 元素 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 顶部栏 | 从上方滑入 + 淡入 | 0.4s | ease-out |
| 指标卡片 | 依次从下方浮入（stagger 0.08s） | 0.5s each | ease-out |
| 漏斗面板 | 从左侧滑入 + 淡入 | 0.6s | ease-out |
| 环形图 | 从 0° 旋转展开 | 1.2s | ease-out |
| 柱状图 | 柱体从底部弹跳生长 | 0.8s | spring |
| 折线图 | 线条从左到右绘制 | 1.0s | ease-in-out |

### 4.2 数据刷新动效

- 数字变化：旧值淡出 → 新值从下浮入（0.3s），或使用 count-up 插值动画（0.6s）
- 图表更新：使用 morphing 过渡，旧图形淡出同时新图形淡入（交叉淡化 0.4s）
- 刷新按钮：点击时旋转 360°（0.6s），同时发出一次脉冲波纹向外扩散

### 4.3 交互微动效

| 交互 | 动效 |
|------|------|
| 面板 hover | 边框亮度 ↑，上浮 2px，底部青色微光阴影，过渡 0.2s ease |
| 按钮/标签 hover | 背景色渐变过渡 0.15s |
| 胶囊按钮切换 | 选中态滑块从左滑入，背景色过渡 0.2s |
| 图表 tooltip | 从鼠标位置淡入弹出（0.15s），带微小上浮 |
| 环形图 hover | 选中段外扩 4px + 发光；其余段透明度降至 0.3 |

### 4.4 氛围动效（Ambient）

- **背景粒子**：页面背景有极淡的缓慢漂浮粒子（canvas 实现），模拟星空/数据流，粒子颜色为 `#00F2FF`，透明度 0.03~0.06，速度极慢（<1px/s），营造「数据空间」沉浸感（可选，不影响性能）
- **网格扫描线**：图表面板底部有一条极淡的横向扫描线，每 3 秒从上到下扫过一次（`rgba(0,242,255,0.03)` 水平线，宽度 100%，过渡 3s linear），模拟雷达/监控系统感觉
- **数据更新时间**：页面顶部更新时间每秒跳动（只跳动秒数），营造「实时连接」感

## 五、状态覆盖

### 5.1 加载态

| 元素 | 加载态表现 |
|------|-----------|
| 指标卡片 | 骨架屏：灰色半透明块脉动（skeleton pulse），尺寸与真实内容一致 |
| 环形图 | 灰色圆环骨架（`rgba(255,255,255,0.06)`），缓慢旋转 |
| 漏斗 | 4 层灰色等宽占位条，逐层脉动 |
| 柱状图 | 3 根灰色占位柱，交替脉动 |
| 折线图 | 灰色区域占位，模拟图表形状的骨架 |

通用：所有骨架屏使用同一脉动节奏（1.5s 周期），颜色 `rgba(255,255,255,0.04)` 在 0.04~0.08 之间呼吸。

### 5.2 空态

| 场景 | 表现 |
|------|------|
| 某区域无数据 | 该区域在图表中显示为 0 值柱体/扇区（极细），悬浮 tooltip 显示「暂无数据」 |
| 全局无数据 | 页面中央显示空态：一个半透明数据折线图标 + 「暂无运营数据」文字（16px `#8B949E`）+ 「请确认数据源连接」辅助文字（14px `#484F58`） |
| 某运营位无数据 | 漏斗切换标签上该位显示灰色，选中后漏斗 4 层均显示为 0 |

### 5.3 错误态

| 场景 | 表现 |
|------|------|
| 单个面板加载失败 | 面板内显示错误图标 + 「数据加载失败」+ 「重试」按钮（文字链接，`#00F2FF` 色），其余正常面板不受影响 |
| 全局加载失败 | 页面中央错误图标 + 「数据连接异常」+ 「请检查网络后重试」+ 重试按钮 |

### 5.4 模拟数据标记

海外区域（北美/欧洲/亚太）使用模拟数据时，对应区域名称旁显示半透明「SIM」徽标（`rgba(255,183,77,0.2)` 背景 + `#FFB74D` 文字，8px pill tag），明确区分真实/模拟数据。
