## 2. 平台侧 — 网络资源分配策略配置

位置：产品审核 → App功能配置 → 默认配置 Tab，在「低电量保护策略」下方新增。

### 关闭态

```
┌──────────────────────────────────────────────┐
│  网络资源分配策略                              │
│  ┌────────────────────────────────────────┐   │
│  │  启用   [开关 OFF]                      │   │
│  └────────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

### 开启态

```
┌──────────────────────────────────────────────┐
│  网络资源分配策略                              │
│  ┌────────────────────────────────────────┐   │
│  │  启用   [开关 ON]                       │   │
│  │                                         │   │
│  │  速率阈值  [ 200 ] KB/s                 │   │
│  │   加载速率低于此值触发慢速提示              │   │
│  │                                         │   │
│  │  提示文案                                │   │
│  │  ┌──────────────────────────────────┐  │   │
│  │  │ 当前网络加载速度缓慢，开通VIP提速     │  │   │
│  │  └──────────────────────────────────┘  │   │
│  └────────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

### 交互

| 行为 | 效果 |
|------|------|
| 切换启用开关 ON | 展开阈值和文案配置区 |
| 切换启用开关 OFF | 收起配置区，保留已填值 |
| 调整阈值 | input-number，步长 50，范围 50–1000 |
| 编辑文案 | el-input，maxlength 50 |

## 5. 提示文案样式规格

| 属性 | 值 |
|------|------|
| 位置 | 视频区内部底部，覆盖于视频画面上方 |
| 对齐 | 左对齐文案 + 右侧"去开通" |
| 背景 | `rgba(0,0,0,0.55)` 半透明黑色 |
| 高度 | 32px |
| 字号 | 12px（文案）/ 12px bold（去开通） |
| 文案颜色 | `rgba(255,255,255,0.85)` |
| "去开通"颜色 | `#FFD54F` 亮黄色（可点击态） |
| 出现 | 淡入 0.3s |
| 消失 | 淡出 0.3s，速率恢复时自动消失 |
| 整行可点击 | "去开通"区域为 tappable，跳转商城 |

---

## 6. 状态说明

| 状态 | 触发条件 | 展示内容 |
|------|------|------|
| 正常态 | VIP 用户 或 视频正常播放中 | 视频区纯画面，无提示 |
| 加载中 | 视频加载/缓冲，速率 < 阈值，未满 5 秒 | 先不展示，等计时判定 |
| 慢速态 | 普通用户 + 加载/缓冲中 + 持续慢速满 5 秒 | 视频区底部半透明提示条 |
| 冷却期 | 提示消失后 30 秒内 | 不触发提示，即使再次慢速 |
| 无网络 | 完全无网络连接 | 由播放器自身错误态处理，不展示速率提示 |

## 7. 组件选型

### 平台侧（Element Plus）

| 组件 | 用途 |
|------|------|
| `el-switch` | 启用开关 |
| `el-input-number` | 速率阈值（50–1000，步长 50） |
| `el-input` | 提示文案输入 |

### APP 侧（Vant + 原生）

| 实现 | 用途 |
|------|------|
| `<div>` + CSS | 半透明提示条（非 Vant 组件，轻量 DOM） |
| `router.push('/store?tab=cloud')` | 跳转服务商城云存储 Tab |
| `v-if` / `v-show` | 提示条显示控制 |
