### 2.2 关键特性

| 特性 | 说明 |
|------|------|
| **筛选 tabs** | 全部 / 智能体 / 工作流 / 高代码（segmented control 风格，非传统 tabs） |
| **搜索** | 按应用名称搜索 + "全部"类型下拉 + 刷新按钮 |
| **卡片展示** | 而非表格！每个应用一张卡片 |
| **卡片信息** | 应用图标、名称、发布状态（tag）、应用ID（可复制）、选用模型（如有）、更新时间 |
| **卡片操作** | 配置按钮、发布按钮（未配置时 disabled）、更多菜单（⋯） |
| **"支付宝AI收"** | 特殊入口按钮（特定业务） |

### 2.3 状态展示

- **未发布**: 灰色 tag 显示在名称旁边；发布按钮 disabled
- **已发布**: 绿色 tag（推测）
- **发布按钮 disabled**: 灰色，hover 提示"请先完成应用配置"

## 三、创建应用弹窗

### 3.1 弹窗结构

采用**左右分栏**布局：

```
┌──────────────────────────────────────────────────┐
│  创建应用                                    [×]  │
├──────────────┬───────────────────────────────────┤
│              │                                   │
│  低代码       │  创建智能体应用                     │
│  ○ 智能体应用  │  构建智能体应用，连接知识、数据与...  │
│  ○ 工作流应用  │                                   │
│              │  类型                              │
│  高代码       │  ○ Agent 2.0 (推荐)                │
│  ○ 高代码应用  │    基于AgentScope开发框架构建...    │
│              │  ○ Agent 1.0                       │
│              │    结合Prompt与多种业务规则...        │
│              │                                   │
│              │  应用名称 *  [_______________] 0/50 │
│              │  描述信息    [_______________]      │
│              │  应用头像    [🖼]                   │
│              │                                   │
├──────────────┴───────────────────────────────────┤
│                              [取消]  [立即创建]     │
└──────────────────────────────────────────────────┘
```

### 3.2 应用类型

| 类型 | 分类 | 说明 |
|------|------|------|
| 智能体应用 | 低代码 | 构建智能体应用，连接知识、插件等 |
| 工作流应用 | 低代码 | 通过画布自定义编排工作流 |
| 高代码应用 | 高代码 | 高代码开发和云上托管的应用 |

### 3.3 Agent 版本

| 版本 | 说明 |
|------|------|
| Agent 2.0 (推荐) | 基于AgentScope开发框架构建，全新Agent模式，强化React与Function Call能力，适用于多工具调用、多步骤决策 |
| Agent 1.0 | 结合Prompt与多种业务规则控制的Agent模式，在知识库检索增强任务上更具稳定性与结果干预 |

### 3.4 设计要点

- 左侧类型选择使用 **radio card** 样式（图标 + 标题 + 描述 + radio）
- 右侧根据所选类型动态切换表单内容
- 应用名称限制 **50 字符**，有计数器
- 头像支持自定义上传
- 必填项用红色 `*` 标注

### 4.2 左侧锚点导航

垂直图标标签，点击滚动到对应区域：

| 标签 | 图标 | 对应区域 |
|------|------|----------|
| 规划 | planning | 模型选择 + 提示词 + 预解析文件 |
| 工具 | tool | 内置工具 + 知识库 + 数据连接器 + 应用组件 + MCP服务 |
| 技能 | toolbox | Skill 配置 |
| 记忆 | memory | 短期记忆（上下文轮数） |
| 环境 | apiKey | 环境变量配置 |
| 回复 | chatAnywhere | 回答来源展示 |

### 4.3 各配置区详情

#### 规划（模型 + 提示词）

| 字段 | 组件 | 说明 |
|------|------|------|
| 模型选择 | combobox + edit button | 下拉选择模型，旁边有编辑按钮 |
| 提示词 | textarea | 大尺寸，占满宽度，高度自适应 |
| 提示词字数 | 计数器 | 0/997952，约 1M 字符限制 |
| 提示词辅助 | "新建变量"按钮 | 支持 `/` 引用变量，Enter 换行 |
| 预解析文件 | switch toggle | 开启后使用预置解析器处理文档/图像/视频/音频 |

#### 工具

| 工具类型 | 说明 |
|----------|------|
| 内置工具 | 百炼内建工具，通过设置按钮管理 |
| 知识库 | 配置后发布为MCP服务接入，为智能体提供补充知识 |
| 数据连接器 | Agent/Workflow/知识库等访问外部数据的桥梁 |
| 应用组件 | 将已创建的智能体或工作流作为组件接入 |
| MCP服务 | 支持插件转MCP，通过插件转换或开通广场中的MCP服务 |

每个工具类型都有 `[+]` 添加按钮。

#### 技能

- Skill 配置区域
- 空态："暂无 Skill，点击右上角「+」开始配置"

#### 记忆

| 字段 | 组件 | 默认值 | 范围 |
|------|------|--------|------|
| 短期记忆 | 开关 | — | — |
| 携带上下文轮数 | slider + spinbutton | 3 | 0-30 |

说明：「短期记忆是会话中提供给智能体的上下文信息，轮数越多，对话相关性越强，输入长度也会增加」

#### 环境

- 环境变量配置
- 用途：「配置 Skill 调用时所需的鉴权密钥和环境变量信息」
- 空态：「暂无环境变量，点击右上角「添加变量」开始配置」

#### 回复

| 字段 | 组件 | 说明 |
|------|------|------|
| 展示回答来源 | switch | 以角标形式展示知识来源，并支持用户获取到源文件地址或源网页地址 |

## 八、关键设计模式总结

### 8.1 信息架构

```
应用管理（卡片列表）→ 配置页（锚点导航长表单 + 右侧调试面板）
                   → 观测（独立页面）
                   → 版本管理
                   → 发布 → 发布渠道配置
```

### 8.2 UI 模式

| 模式 | 应用位置 |
|------|----------|
| **卡片网格** | 应用列表页，非表格 |
| **左右分栏弹窗** | 创建应用 |
| **锚点导航 + 长表单** | 智能体配置页（左侧垂直icon tabs，右侧滚动表单） |
| **右侧调试面板** | 配置页内嵌对话测试 |
| **Segmented Control** | 列表筛选（全部/智能体/工作流/高代码）|
| **空态+引导** | 任务中心、技能、环境变量 |
| **模板卡片** | Managed Agents 快速开始 |

### 8.3 与我们的 IoT 平台的差异

| 百炼 | IoT 平台（当前） |
|------|------------------|
| 卡片列表 | 表格列表 |
| 左侧锚点导航长表单 | el-drawer 内 tabs |
| 配置页内嵌调试面板 | 调试为独立 drawer |
| 创建为弹窗（左右分栏） | 创建为 drawer |
| segmented control 筛选 | el-select 下拉筛选 |
| 模型管理在创建流程中 | 模型管理为独立页面 |

### 8.4 可借鉴的设计

1. **卡片列表优于表格**：应用管理用卡片更直观，可看到应用图标、状态
2. **锚点导航 + 长表单**：配置项多时，左侧锚点导航比 tabs 更易导航
3. **配置页内嵌调试**：不需要单独打开调试面板，直接右侧对话
4. **创建应用左右分栏**：左侧选类型，右侧填信息，一步完成
5. **发布渠道独立 tab**：配置完成后发布到不同渠道
6. **应用ID 可复制**：每张卡片显示应用ID，带复制按钮
