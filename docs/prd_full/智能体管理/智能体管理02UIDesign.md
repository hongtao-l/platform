## 一、页面结构

```
智能体列表页 (/agent)
├── 筛选栏
│   ├── 智能体名称（搜索框）
│   ├── 绑定模型（下拉筛选）
│   └── 状态（启用/停用 下拉筛选）
├── 工具栏
│   ├── [创建智能体] （主按钮）
│   └── [模型管理] （次要按钮）
├── 数据表格
│   ├── 算法名称（首列，支持点击进入编辑）
│   ├── 绑定模型
│   ├── 关联算法（数量 badge）
│   ├── 状态（开关切换）
│   ├── 更新时间
│   └── 操作（编辑 / 调试 / 删除）
├── 分页栏

智能体配置抽屉（el-drawer, 800px）
├── Tab: 基础配置
│   ├── 智能体名称（输入框）
│   ├── 描述（输入框）
│   ├── 绑定模型（下拉，仅显示已启用模型）
│   ├── 系统提示词（Textarea，大尺寸）
│   └── 模型参数
│       ├── 温度 Temperature（滑块 + 数值输入，0~2.0，步长 0.1）
│       ├── 最大 Token（滑块 + 数值输入，256~128000）
│       └── Top-P（滑块 + 数值输入，0~1.0，步长 0.05）
├── Tab: 工具绑定（P1，首期空态）
│   └── 空态：暂无可用工具
└── 底部按钮：[取消] [保存]

模型管理弹窗（el-dialog, 700px）
├── 模型列表表格
│   ├── 厂商名称
│   ├── 模型标识
│   ├── API Key（掩码显示，仅展示后 4 位）
│   ├── 状态（开关）
│   └── 操作（编辑 / 删除）
├── 顶部按钮：[添加模型]
└── 添加/编辑模型表单（同一弹窗内切换或子弹窗）

在线调试面板（el-drawer, 600px）
├── 调试区域
│   ├── 消息列表（对话气泡，用户消息靠右，智能体回复靠左）
│   ├── 输入区域（textarea + 发送按钮）
│   └── 指标栏（耗时 / Token 消耗）
├── 工具栏
│   ├── [清空对话]
│   ├── 临时模型切换（下拉，可选覆盖智能体配置的模型）
│   └── 临时温度调整（滑块）
└── 底部：[关闭]
```

## 二、页面布局详述

### 2.1 智能体列表页

**入口**: 侧栏「物模型管理」下新增「智能体管理」菜单项

**整体布局**：
```
┌──────────────────────────────────────────────────┐
│  筛选栏                                          │
│  [智能体名称___] [绑定模型▾] [状态▾] [查询][重置] │
├──────────────────────────────────────────────────┤
│  工具栏                          [模型管理][创建智能体] │
├──────────────────────────────────────────────────┤
│  表格                                            │
│  ┌──────────────────────────────────────────────┐│
│  │ 算法名称 │ 绑定模型 │ 关联算法 │ 状态 │ 更新 │ 操作 ││
│  │ 全能AI助手│ Qwen-Max │ 3个算法   │ ●启用 │ ...  │ ... ││
│  │ 厨房安全  │ ERNIE-4  │ 1个算法   │ ○停用 │ ...  │ ... ││
│  └──────────────────────────────────────────────┘│
│  共 N 条              [<] [1] [2] [>]            │
└──────────────────────────────────────────────────┘
```

**筛选栏**：复用 `.filter-bar` 样式（`bg-card` 背景，`border-lighter` 边框，8px 圆角）

**表格列定义**：
| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 算法名称 | min-width:160 | 左 | 加粗，primary 色，点击可进入编辑 |
| 绑定模型 | 140 | 左 | 显示模型标识（如 Qwen-Max），tag 样式 |
| 关联算法 | 100 | 居中 | 数量 badge，点击可展开算法列表 Tooltip |
| 状态 | 90 | 居中 | el-switch，切换启用/停用 |
| 更新时间 | 160 | 左 | 次要文字色 |
| 操作 | 180 | 居中 | [编辑] [调试] [删除] 文字按钮 |

**空态**：
- 占位图标 + 「暂无智能体」+ 「创建第一个智能体」引导按钮

### 2.2 智能体配置抽屉

**触发**：列表页点击「创建智能体」或某行「编辑」

**抽屉尺寸**：800px（与套餐配置抽屉一致）

**Tab 区域**：
```
┌─────────────────────────────────────────┐
│  创建智能体                        [×]  │
├─────────────────────────────────────────┤
│  [基础配置]  [工具绑定]                  │  ← el-tabs
├─────────────────────────────────────────┤
│                                         │
│  智能体名称  [___________________]       │
│                                         │
│  描述        [___________________]       │
│                                         │
│  绑定模型    [▾ 通义千问 Qwen-Max    ]   │
│                                         │
│  系统提示词                               │
│  ┌─────────────────────────────────┐    │
│  │ 你是一个智能家居安全助手...       │    │
│  │                                 │    │
│  │                          (800px) │    │
│  └─────────────────────────────────┘    │
│                                         │
│  ── 模型参数 ───────────────────────    │
│  温度     [====○========] 0.7           │
│  最大Token [========○====] 4096         │
│  Top-P    [======○======] 0.9          │
│                                         │
├─────────────────────────────────────────┤
│                         [取消]  [保存]   │
└─────────────────────────────────────────┘
```

**表单规范**：
- `label-width="100px"` 或 `label-position="top"`
- 提示词 textarea：`type="textarea"` `rows="10"`，等宽字体
- 参数滑块：`el-slider` + 右侧 `el-input-number` 组合，一行三个参数
- 抽屉 body `padding-top: 20px`

**工具绑定 Tab（首期空态）**：
- 空态提示：「暂无可用工具，工具/插件功能将在后续版本上线」
- 仅展示占位，不可操作

**弹窗**：`el-dialog`，width 700px

```
│              [+ 添加模型]             │
```

### 2.4 在线调试面板

**触发**：列表页某行「调试」按钮，或编辑抽屉内「调试」Tab

**实现方式**：独立 `el-drawer`，600px

```

│  智能体调试 - 全能AI助手         [×] │

│        ┌──────────────────┐          │
│        │ 帮我分析这张截图   │ ← 用户  │
│        └──────────────────┘          │
│                                      │
│  ┌──────────────────────────┐        │
│  │ 好的，从截图来看...       │ ← 智能体│
│  │ 耗时 1.2s · Token 456    │        │

│                                      │

│                                      │
```

**对话气泡样式**：
- 用户消息：右对齐，`primary` 浅色背景，圆角 8px
- 智能体回复：左对齐，`bg-card` 背景，圆角 8px
- 每条智能体回复底部附耗时 + Token 指标

**工具栏**：
- 清空对话：文字按钮
- 模型切换：`el-select` 小尺寸，默认跟随智能体配置
- 温度滑块：`el-slider` 小尺寸，默认跟随智能体配置

## 三、状态说明

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 列表正常态 | 有数据 | 表格展示智能体列表 |
| 列表空态 | 0 条数据 | 空态图标 + 「暂无智能体」+ 创建引导按钮 |
| 列表加载态 | 数据请求中 | 表格 skeleton / loading |
| 配置正常态 | 打开创建/编辑 | 表单正常展示 |
| 调试正常态 | 开始调试 | 对话区域正常交互 |
| 调试错误态 | 模型调用失败 | 错误消息以红色气泡形式展示 |
| 调试加载态 | 等待模型回复 | 智能体侧显示 typing dots（...）动画 |
| 停用态 | 智能体已停用 | 状态列为灰色开关，调试按钮置灰不可点击 |
| 模型缺失态 | 绑定的模型被删除 | 编辑时模型下拉标红提示「模型不可用」 |

## 四、关键交互说明

1. **列表页→编辑**：点击智能体名称或「编辑」按钮 → 打开配置抽屉，回填数据
2. **列表页→调试**：点击「调试」→ 打开调试抽屉，带入智能体配置
3. **编辑页→调试**：编辑抽屉底部可加「去调试」按钮，保存后跳转调试
4. **启用/停用**：列表页直接切换开关，即时生效，无需二次确认
5. **删除确认**：`ElMessageBox.confirm` 弹窗，被算法引用时提示「已被 N 个算法引用」
6. **模型删除保护**：被智能体引用的模型不可删除，提示解绑后操作

## 五、组件清单

| 组件 | Element Plus 组件 | 用途 |
|------|-------------------|------|
| 筛选栏 | `el-input` + `el-select` + `el-button` | 搜索筛选 |
| 数据表格 | `el-table` + `el-switch` | 列表展示 + 行内状态切换 |
| 分页 | `el-pagination` | 翻页 |
| 配置抽屉 | `el-drawer` + `el-tabs` + `el-form` | 创建/编辑智能体 |
| 提示词输入 | `el-input` textarea | 长篇文本输入 |
| 参数滑块 | `el-slider` + `el-input-number` | 温度/Token/Top-P控制 |
| 模型管理弹窗 | `el-dialog` + `el-table` | 模型 CRUD |
| 模型表单 | `el-dialog`（子弹窗） + `el-form` + `el-select` + `el-input` | 添加/编辑模型 |
| 调试面板 | `el-drawer` + 自定义对话气泡 | 在线测试 |
| 删除确认 | `ElMessageBox.confirm` | 删除二次确认 |
| 提示反馈 | `ElMessage` | 操作结果 Toast |

## 七、样式要点

- 复用 `.filter-bar`、`.card`、`.page-container` 现有 class
- 参数滑块区域使用 `.param-sliders` 容器，三个滑块等宽排列
- 调试消息列表使用 `.debug-messages` 容器，`max-height` 填充剩余空间
- 对话气泡 `.msg-bubble` + `.msg-user` / `.msg-agent` 修饰类
- 弹窗覆盖样式使用**非 scoped** `<style lang="scss">` 块
- 工具绑定空态复用 `.transfer-empty` 样式
