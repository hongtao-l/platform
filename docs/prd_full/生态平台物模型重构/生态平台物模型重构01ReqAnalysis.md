## 一、业务背景

### 1.1 业务场景

IoT 平台面向平台管理员、设备厂商与平台运营人员，提供设备能力定义、类目管理、产品配置与产品审核能力。

**物模型管理**

- 能力库：由平台维护能力模块、能力项与参数，形成平台标准能力资产。
- IOT 类目：由平台维护设备类目树，并将能力库中的能力项关联到类目。
- 类目能力详情：查看某个类目已关联的能力项与参数，管理关联关系。

**产品管理**

- 产品开发：查询、创建产品，并按产品状态进入开发、复制或删除。
- 开发产品：按「功能定义与配置 → APP 控制面板配置 → 平台服务 & 发布」三步完成产品配置。
- 产品审核：平台对企业提交的产品进行审核、赠送授权与管理。
- 产品详情：查看产品基本信息、物模型配置、平台服务、APP 配置、语音助手与固件历史。

### 1.2 目标用户与业务价值

| 角色 | 使用场景 | 业务价值 |
|---|---|---|
| 设备厂商 / 产品经理 | 从能力库选用标准能力，配置产品功能与 APP 面板 | 复用平台标准能力，减少重复配置 |
| 固件 / 研发人员 | 查看 TSL、能力项与参数定义 | 获得可直接对接的统一数据结构 |
| 平台运营 | 审核企业产品、赠送授权、管理产品 | 完成产品准入与授权管理 |
| 平台管理员 | 维护能力库（模块/能力项/参数）与类目树 | 保证平台能力资产与类目统一、可复用 |

### 1.3 业务目标

| 目标 | 说明 |
|---|---|
| 能力资产统一 | 平台统一维护能力库与类目，作为产品配置的统一数据源 |
| 类目能力关联 | 类目可关联标准能力项，产品创建时按类目复用能力 |
| 产品全流程配置 | 从产品创建、功能定义、APP 配置到平台服务，形成完整闭环 |
| 审核与授权 | 支持产品审核、赠送授权与自动赠送授权配置 |
| 交互一致 | 菜单、返回、筛选、模块切换、关联能力等交互全局统一 |
| 参数模型统一 | 能力项保留属性/服务/事件类型，参数统一按属性内容配置 |

## 二、名词解释

| 术语 | 说明 |
|---|---|
| 物模型 | 对设备能力的数据化描述，包括属性、服务、事件 |
| 能力模块 | 对能力项进行归类的分组，如工作模式模块、录制模式模块 |
| 能力项 | 物模型能力的载体，分为属性、服务、事件三种类型 |
| 参数 | 能力项下的数据字段，用于描述能力的数据结构；参数统一按属性内容配置 |
| 能力库 | 全平台标准能力项的集合，按模块管理 |
| 类目 | 设备类目树，如 IPC 摄像机、智能门铃、香薰机 |
| 关联能力 | 将能力库中的能力项绑定到某个类目 |
| TSL | Thing Specification Language，平台下发给设备的物模型描述 |
| 产品 | 一组具有相关功能定义的设备集合 |
| 开发产品 | 对产品进行功能定义、APP 配置与平台服务配置的流程 |
| 产品审核 | 平台对企业提交的产品进行审核、赠送授权与管理的流程 |
| 引用产品 | 来自其他企业、当前企业只能只读使用的产品 |
| 标准开发 / 自定义开发 | 产品的两种开发方式 |

## 四、场景穷举分析

### 4.1 能力库

#### 4.1.1 功能概述

- 功能目的：由平台统一维护标准能力模块、能力项与参数，供类目关联与产品配置引用。
- 维护者：平台管理员。
- 前置条件：平台管理员已进入物模型管理 → 能力库。

#### 4.1.2 正常场景

| 场景编号 | 场景名称 | 前置条件 | 操作步骤 | 预期结果 | 状态变化 |
|---|---|---|---|---|---|
| N-101 | 新增模块 | 已进入能力库 | 点击「添加」→ 填写模块名称/标识 → 确定 | 模块出现在左侧列表，标识唯一 | 模块列表 +1 |
| N-102 | 编辑模块 | 模块已存在 | 悬浮模块 → 点击编辑 → 修改 → 确定 | 模块名称/标识更新，关联能力同步显示新模块名 | 模块信息更新 |
| N-103 | 删除模块 | 模块已存在 | 悬浮模块 → 删除 → 二次确认 | 模块及其下能力、能力项、类目关联一并删除 | 模块列表 -1 |
| N-104 | 新增能力项 | 已进入能力库 | 点击「添加能力项」→ 填类型/名称/ID/所属模块 → 可先加参数 → 确定 | 能力项出现在表格，可展开查看参数 | 能力项 +1 |
| N-105 | 编辑能力项 | 能力项已存在 | 行内「编辑」→ 修改 → 确定 | 能力项信息更新，参数保留 | 能力项更新 |
| N-106 | 删除能力项 | 能力项已存在 | 行内「删除」→ 二次确认 | 能力项及其下参数删除，类目关联同步解除 | 能力项 -1 |
| N-107 | 添加参数 | 能力项已存在 | 行内「添加参数」→ 填写参数属性信息 → 提交 | 参数出现在展开子表 | 参数 +1 |
| N-108 | 编辑参数 | 参数已存在 | 展开能力项 → 参数行「编辑」→ 修改 → 提交 | 参数信息更新 | 参数更新 |
| N-109 | 删除参数 | 参数已存在 | 展开能力项 → 参数行「删除」→ 二次确认 | 参数删除，类目关联同步解除 | 参数 -1 |
| N-110 | 按模块筛选 | 存在多个模块 | 点击左侧模块 | 右侧仅展示该模块能力项 | 当前模块切换 |
| N-111 | 按类型筛选 | 存在多种类型 | 点击全部/属性/服务/事件 | 表格仅展示对应类型，计数同步 | 类型筛选切换 |
| N-112 | 搜索能力项 | 能力项较多 | 输入名称或标识 | 表格展示匹配结果 | 搜索条件生效 |
| N-113 | 分页 | 能力项超过一页 | 切换页码或每页条数 | 表格展示对应页数据，底部统计同步 | 分页切换 |

#### 4.1.3 异常场景

| 场景编号 | 异常类型 | 触发条件 | 系统行为 | 用户感知 |
|---|---|---|---|---|
| E-101 | 必填为空 | 模块名称/标识为空 | 阻止提交 | 表单错误提示 |
| E-102 | 标识格式错误 | 模块/能力项/参数标识非字母开头或含非法字符 | 阻止提交 | 明确格式提示 |
| E-103 | 标识重复 | 模块、能力项或参数标识已存在 | 阻止提交 | 提示更换标识 |
| E-104 | 数值边界错误 | 数值型最大值 ≤ 最小值 | 阻止提交 | 提示最大值必须大于最小值 |
| E-105 | 枚举为空 | 枚举型没有有效枚举值 | 阻止提交 | 提示至少一个枚举值 |
| E-106 | 数据为空 | 当前模块无能力项 | 表格空态 | 显示「暂无能力项」+ 添加入口 |
| E-107 | 删除关联数据 | 删除模块/能力项/参数 | 二次确认并说明影响范围 | 明确提示将同步删除/解绑 |
| E-108 | 切换参数类型 | 已填写内容后切换类型 | 二次确认 | 提示清空当前数据定义 |

#### 4.1.4 边界条件

| 条件项 | 最小值 | 最大值 | 默认值 | 超限行为 |
|---|---|---|---|---|
| 单页条数 | 20 | 100 | 20 | 仅允许预设档位 |
| 枚举值数量 | 1 | 未限制 | 1 | 至少保留一条有效枚举 |
| 数值型范围 | 由用户填写 | 由用户填写 | 0~100 | 最大值必须大于最小值 |
| 字符串长度 | 1 | 65535 | 64 | 超出提示 |
| 数组元素个数 | 1 | 1000 | 100 | 超出提示 |
| 模块/能力项/参数名称 | 2 | 50 | — | 超出提示 |

#### 4.1.5 状态流转

- 能力项状态：无（能力项无发布状态，直接生效）。
- 类型状态：属性 / 服务 / 事件，可在新增时选择；编辑能力项类型不改变已有参数。
- 参数状态：统一按属性内容配置，不区分属性/服务/事件。

## 五、跨模块联动分析

| 联动关系 | 说明 |
|---|---|
| 能力库 → 类目 | 类目关联能力时读取能力库的能力项与参数；能力删除/参数删除时同步解除类目关联 |
