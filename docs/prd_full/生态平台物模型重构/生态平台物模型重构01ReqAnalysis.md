## 一、业务背景

### 1.1 业务场景

生态平台面向平台管理员、设备厂商与平台运营人员，提供物模型能力管理、类目管理、产品开发与产品审核能力。

本期聚焦以下四个功能：

1. **能力库**：平台维护能力模块、能力项与参数，形成标准能力资产。
2. **物模型类目**：平台维护设备类目树，并将能力库能力项关联到类目。
3. **产品开发-继续开发**：产品开发列表中点击「继续开发」进入的产品配置页。
4. **产品审核-管理产品的物模型配置**：产品审核中点击「管理产品」进入产品详情后，查看/修改产品物模型配置。

### 1.2 目标用户与业务价值

| 角色 | 使用场景 | 业务价值 |
|---|---|---|
| 平台管理员 | 维护能力库与物模型类目 | 保证平台能力资产与类目统一、可复用 |
| 设备厂商 / 产品经理 | 通过继续开发配置产品能力 | 复用标准能力，快速完成产品功能定义 |
| 平台运营 | 审核产品并管理产品物模型 | 完成产品准入与物模型配置 |
| 固件 / 研发人员 | 查看 TSL、能力项与参数定义 | 获得可直接对接的统一数据结构 |

### 1.3 业务目标

| 目标 | 说明 |
|---|---|
| 能力资产统一 | 平台按模块维护能力项与参数，作为类目与产品的统一数据源 |
| 类目能力关联 | 类目可关联标准能力项，产品按类目复用能力 |
| 继续开发闭环 | 从产品开发进入配置页，完成功能定义、APP 配置与平台服务 |
| 物模型可管理 | 审核管理入口可查看/修改产品物模型配置 |
| 交互一致 | 菜单、返回、筛选、模块切换、关联能力等交互统一 |

### 1.4 本期范围

本次只覆盖上述四个功能。以下功能**沿用现有能力**，不在本文档展开：

- 产品列表、创建产品
- 产品开发列表的筛选、状态操作、复制、删除
- 产品审核列表、审核、赠送授权、自动赠送授权
- 产品详情中除「物模型配置」外的其他信息
- 开发产品中的 APP 控制面板配置、平台服务（复用现有）
- 套餐管理、智能体管理、运营管理、算法库、事件库

## 二、名词解释

| 术语 | 说明 |
|---|---|
| 物模型 | 对设备能力的数据化描述，包括属性、服务、事件 |
| 能力模块 | 对能力项进行归类的分组 |
| 能力项 | 物模型能力的载体，分为属性、服务、事件 |
| 参数 | 能力项下的数据字段，统一按属性内容配置 |
| 能力库 | 平台标准能力项的集合，按模块管理 |
| 类目 | 设备类目树 |
| 关联能力 | 将能力库中的能力项绑定到类目 |
| TSL | 平台下发给设备的物模型描述 |
| 继续开发 | 产品开发列表中进入产品配置页的入口 |
| 管理产品 | 产品审核中进入产品详情页的入口 |
| 物模型配置 | 产品详情中查看/修改产品能力项与参数的配置 |

## 四、场景穷举分析

### 4.1 能力库

#### 4.1.1 功能概述

- 功能目的：由平台统一维护标准能力模块、能力项与参数，供类目关联与产品配置引用。
- 维护者：平台管理员。
- 前置条件：平台管理员已进入物模型管理 → 能力库。

#### 4.1.2 正常场景

| 场景编号 | 场景名称 | 前置条件 | 操作步骤 | 预期结果 | 状态变化 |
|---|---|---|---|---|---|
| N-101 | 新增模块 | 已进入能力库 | 点击「添加」→ 填写模块名称/标识 → 确定 | 模块出现在左侧列表，标识唯一 | 模块列表 +1 |
| N-102 | 编辑模块 | 模块已存在 | 悬浮模块 → 编辑 → 修改 → 确定 | 模块信息更新，能力显示新模块名 | 模块更新 |
| N-103 | 删除模块 | 模块已存在 | 悬浮模块 → 删除 → 二次确认 | 模块及其能力项、参数、类目关联一并删除 | 模块 -1 |
| N-104 | 新增能力项 | 已进入能力库 | 点击「添加能力项」→ 填类型/名称/ID/模块 → 可先加参数 → 确定 | 能力项出现在表格，可展开参数 | 能力项 +1 |
| N-105 | 编辑能力项 | 能力项已存在 | 行内「编辑」→ 修改 → 确定 | 能力项更新，参数保留 | 能力项更新 |
| N-106 | 删除能力项 | 能力项已存在 | 行内「删除」→ 二次确认 | 能力项及参数删除，类目关联解除 | 能力项 -1 |
| N-107 | 添加参数 | 能力项已存在 | 行内「添加参数」→ 配置属性内容 → 提交 | 参数出现在展开子表 | 参数 +1 |
| N-108 | 编辑参数 | 参数已存在 | 展开能力项 → 参数行「编辑」→ 修改 → 提交 | 参数更新 | 参数更新 |
| N-109 | 删除参数 | 参数已存在 | 展开能力项 → 参数行「删除」→ 二次确认 | 参数删除，类目关联解除 | 参数 -1 |
| N-110 | 按模块筛选 | 存在多个模块 | 点击左侧模块 | 仅展示该模块能力项 | 筛选切换 |
| N-111 | 按类型筛选 | 存在多种类型 | 点击全部/属性/服务/事件 | 表格与计数同步 | 筛选切换 |
| N-112 | 搜索能力项 | 能力项较多 | 输入名称或标识 | 展示匹配结果 | 搜索生效 |
| N-113 | 分页 | 超过一页 | 切换页码/每页条数 | 展示对应页数据 | 分页切换 |

#### 4.1.3 异常场景

| 场景编号 | 异常类型 | 触发条件 | 系统行为 | 用户感知 |
|---|---|---|---|---|
| E-101 | 必填为空 | 模块名称/标识为空 | 阻止提交 | 表单错误提示 |
| E-102 | 标识格式错误 | 非字母开头或含非法字符 | 阻止提交 | 格式提示 |
| E-103 | 标识重复 | 模块/能力项标识全局重复；参数标识在同一能力项下重复 | 阻止提交 | 提示更换标识 |
| E-104 | 数值边界错误 | 数值型/浮点型最大值 ≤ 最小值 | 阻止提交 | 提示最大值必须大于最小值 |
| E-105 | 枚举为空 | 枚举型没有有效枚举值 | 阻止提交 | 提示至少一个枚举值 |
| E-106 | 数据为空 | 当前模块无能力项 | 表格空态 | 「暂无能力项」+ 添加入口 |
| E-107 | 删除关联数据 | 删除模块/能力项/参数 | 二次确认并说明影响范围 | 明确提示同步删除/解绑 |

#### 4.1.4 边界条件

| 条件项 | 最小值 | 最大值 | 默认值 | 超限行为 |
|---|---|---|---|---|
| 单页条数 | 20 | 100 | 20 | 仅允许预设档位 |
| 枚举值数量 | 1 | 未限制 | 1 | 至少保留一条有效枚举 |
| 数值型范围 | 由用户填写 | 由用户填写 | 0~100 | 最大值必须大于最小值 |
| 浮点型范围 | 由用户填写 | 由用户填写 | 0~100 | 最大值必须大于最小值；支持任意位小数；步长默认 0.1 |
| 字符串长度 | 1 | 65535 | 64 | 超出提示 |
| 数组元素个数 | 1 | 1000 | 100 | 超出提示 |
| 模块/能力项/参数名称 | 2 | 50 | — | 超出提示 |

参数数据类型：枚举型、数值型（Int）、浮点型（Double）、布尔型、字符串、数组型、结构体型。

#### 4.1.5 状态流转

- 能力项类型：属性 / 服务 / 事件，新增时选择。
- 参数层统一按属性内容配置，不区分属性/服务/事件。
- 参数标识在同一能力项下唯一，不同能力项可重复。

### 4.4 产品审核-管理产品的物模型配置

#### 4.4.1 功能概述

- 功能目的：平台运营在产品审核中点击「管理产品」进入产品详情，查看/修改产品物模型配置。
- 实现方式：以弹窗形式承载「继续开发」页面的功能定义与配置内容，仅保留平台标准能力项、自定义能力项、参数与 TSL；不包含产品信息卡、步骤条、APP 配置与平台服务。
- 前置条件：产品存在于产品审核列表。

#### 4.4.2 正常场景

| 场景编号 | 场景名称 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| N-401 | 进入产品详情 | 产品审核列表 | 点击「管理产品」 | 进入产品详情 |
| N-402 | 查看物模型配置 | 产品详情 | 点击物模型配置「查看/修改」 | 打开物模型配置弹窗 |
| N-403 | 查看标准能力 | 弹窗已打开 | 查看平台标准能力项 | 展示能力项与参数 |
