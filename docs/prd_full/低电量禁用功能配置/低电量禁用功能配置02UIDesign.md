## 1. 改动范围

## 4. 交互行为

| 行为 | 触发 | 效果 |
|------|------|------|
| 开启策略 | 切换启用开关 ON | 展开阈值输入和禁用功能选择区 |
| 关闭策略 | 切换启用开关 OFF | 收起配置区，保留已填值 |
| 修改阈值 | 调整 input-number | 正常输入，范围 1–100 |
| 勾选禁用功能 | 点击 checkbox | 选中/取消 |
| 保存 | 点击「保存配置」 | 随默认配置一起保存 |

---

## 5. 字段规格

| 字段 | 组件 | 属性 |
|------|------|------|
| 启用开关 | `el-switch` | 默认 OFF |
| 低电量阈值 | `el-input-number` | `:min="1" :max="100"`，默认 20，后跟 % |
| 禁用功能 | `el-checkbox-group` | 三个 `el-checkbox`：PTZ控制、语音对讲、一键呼叫 |

---

## 6. 布局规则

| 属性 | 值 |
|------|------|
| 区块背景 | `var(--gray-50)`，圆角 6px，padding 12px |
| 阈值行 | label「低电量阈值」，控件 width 120px，后跟 `%` + 灰色提示文字 |
| 禁用功能行 | label「禁用功能」，checkbox 纵向排列 |
| 区块与上方配置项间距 | `margin-top: 8px` |

---

## 7. 数据模型

```javascript
lowBatteryPolicy: {
  enabled: false,
  threshold: 20,
  disabledFeatures: []  // ['ptz', 'talk', 'call']
}
```
