# 三方 ID 设备接入 — unique_id 导入操作手册

> 适用对象：设备厂商 / 生产端操作人员
> 适用场景：不烧录 License 的蓝牙设备（如香薰机），批量导入设备唯一标识 `unique_id`

---

## 一、导入前准备

| 准备项 | 说明 |
|---|---|
| 产品已创建 | 已在平台创建产品，并拿到该产品的 `productId` |
| unique_id 清单 | 由厂商自行定义（MAC 地址、芯片 ID、厂商 SN 均可），**企业范围内唯一** |
| 导入文件 | CSV 或 Excel（.xls / .xlsx），编码 UTF-8 |
| 批次号 | 必填，用于区分和追溯每次导入 |

> 导入的是**设备生产数据**，不需要烧录 License，也不需要修改设备固件。

## 二、文件格式

文件第一行必须是列名，只填写 `unique_id` 一列：

```csv
unique_id
ABCDEFGHIJKLMN
CCDDEEFFAABB
```

要求：

- 列名固定为 `unique_id`，不要增删列、不要合并单元格
- 一行一个 `unique_id`
- 不要留空行
- `unique_id` 必须与设备蓝牙广播中的值**完全一致**（包括大小写、字符和空格）

## 三、导入步骤

### 步骤 1：进入导入页面

登录平台，进入「三方 ID 设备接入 / 生产导入」页面，确认当前导入的目标产品是否正确。

**【截图位置 3：导入页面】**

### 步骤 2：填写批次号

填写本次导入的批次号，例如 `20261022-01`。

> 批次号必填，建议使用「日期 + 序号」格式，便于后续查询和追溯。

### 步骤 3：上传文件

点击上传，选择准备好的 CSV / Excel 文件。

**【截图位置 4：上传文件 + 批次号填写】**

### 步骤 4：提交导入

点击「导入」/「提交」，等待处理完成。

- 导入过程中请勿重复点击
- 文件较大时请耐心等待，避免关闭页面

### 步骤 5：查看导入结果

导入完成后页面会显示：

| 结果 | 说明 |
|---|---|
| 成功数量 | 已生成 License 的 unique_id 数量 |
| 失败数量 | 未导入成功的数量 |
| 失败明细 | 行号 + 失败原因 |

点击失败数量可查看具体失败行和原因，按提示修正后重新导入。

## 四、常见失败原因

| 失败提示 | 原因 | 处理方式 |
|---|---|---|
| 文件格式不支持 | 不是 CSV / Excel，或文件损坏 | 另存为 CSV / .xlsx 后重试 |
| 未填写批次号 | 批次号为空 | 填写批次号后重新提交 |
| unique_id 为空 | 该行没有填写内容 | 补全后重新导入 |
| unique_id 重复 | 文件内出现重复值 | 删除重复行；系统保留第一条 |
| unique_id 已导入 | 该设备之前已经导入过 | 不会重复生成 License，原映射保持不变；无需再次导入 |
| 网络异常 / 导入中断 | 网络或服务异常 | 刷新页面确认导入记录后重试 |

## 五、注意事项

1. **一个 unique_id 只能对应一台设备**
   不要给多台设备使用同一个 unique_id，也不要重复导入同一台设备。

2. **导入值必须和设备广播一致**
   平台不校验 unique_id 格式，但添加设备时会用广播中的值反查。导入值与广播值不一致，会导致设备添加时提示「设备未注册」。

3. **重复导入不会重复生成 License**
   已经导入过的 unique_id 再次导入会被识别为重复，原有 License 和映射关系保持不变。

4. **文件内重复只保留第一条**
   同一文件中出现相同 unique_id 时，第一条有效，后续重复行计入失败明细。

5. **空值行不影响其他行**
   某一行为空只会导致该行失败，其他合法行仍会正常导入。

6. **License 生成失败会整批回滚**
   该批次不会产生半成品数据，可修正后重新导入。

7. **导入成功后建议核对**
   确认成功数量与清单数量一致，并保留批次号和原始文件，便于后续对账。

8. **导入后添加设备失败？**
   先确认导入是否成功、unique_id 是否与广播一致；数据同步可能存在短暂延迟，可稍后重试。仍失败时联系平台并提供批次号和 unique_id。
