## 一、业务背景

wildeye 是面向海外市场的摄像机管理 APP，v1.0.0 为最小可用版本，仅覆盖核心监控闭环：绑设备 → 看直播 → 查回放 → 收告警 → 改设置。

**范围原则**：
- 不做增值服务（云存储套餐、AI 服务）、不做支付、不做社交/社区/商城
- 兼容旭景低功耗设备和长电设备

---

## 二、名词解释

| 术语 | 说明 |
|------|------|
| 低功耗设备 | 电池供电，无事件时休眠，事件触发或用户查看时唤醒 |
| 长电设备 | 持续供电，始终保持在线 |
| P2P | APP 与设备点对点直连，延迟低 |

## 四、功能描述

### 4.1 登录/注册

支持手机号/邮箱注册，密码登录/验证码登录/Apple ID/Google 登录，忘记密码。

默认保持登录 30 天，输错 5 次锁定 15 分钟。首次注册自动创建默认家庭「My Home」。

### 4.2 首页设备列表

展示已绑定设备卡片（封面快照、设备名称、在线状态），在线优先排序。点击进入实时视频，长按进入设备设置/删除。下拉刷新。

低功耗设备封面每次唤醒时刷新，长电设备实时刷新。

### 4.3 添加设备

扫码/蓝牙/AP 三种配网方式，配网超时 120 秒。仅支持 2.4GHz Wi-Fi。一个设备仅可绑定一个账户。

### 4.4 实时视频

P2P 优先，失败降级云中转。基础操作：截图、本地录制、清晰度切换、语音对讲、全屏横屏。支持 PTZ 控制的机型展示方向键和预置位。

低功耗设备需唤醒等待（超时 15s），切后台自动停流。

### 4.5 回放

时间轴拖动，有录像时段高亮，事件标记红色。播放控制：暂停/倍速/截图/录制片段。仅从设备 TF 卡读取，无卡时提示。

低功耗设备仅支持事件录像，长电设备支持全天录像。

### 4.6 设备设置

基础设置项：设备名称、指示灯、工作模式、侦测告警、录像、Wi-Fi、音量、存储管理、固件升级、删除设备、重启、恢复出厂。

低功耗设备部分设置项受限（无不间断录像），休眠期间修改设置标记为待下发。

### 4.7 消息页面

按设备+时间展示告警消息列表，消息详情含事件截图和「查看回放」按钮，可跳转到回放页定位事件时刻。支持左滑删除。

### 4.8 我的页面

账户信息、帮助与反馈、关于、隐私协议/用户协议、注销账户、退出登录。

## 五、设备兼容性差异

| 维度 | 低功耗设备 | 长电设备 |
|------|------|------|
| 休眠 | 无事件时休眠，进入直播需唤醒 | 始终在线 |
| 录制 | 仅事件录像 | 全天 + 事件录像 |
| 对讲 | 半双工 | 半双工 / 全双工 |
| 设置下发 | 唤醒后同步 | 实时下发 |
| 固件升级 | 需电量 ≥ 30% | 无限制 |
