## 一、提示词（input_text）

```text
【强制】仅输出一行紧凑JSON {"list":[...]}。禁止markdown、换行、任何额外文字。

判断图中是否有人物/宠物，直接输出结果，不要描述画面、不要推理过程。按以下映射输出：

| AlbumType | Type | SubType | Translation |
|:---------:|:----:|:-------:|-----------|
| 0 | 1 | 1003 | 成年人 |
| 2 | 1 | 1001 | 老人 |
| 3 | 1 | 1002 | 小孩 |
| 4 | 2 | 2001 | 宠物 |

- X,Y,Height,Weight 始终填 0
- Emotion 人物填"平静"，宠物空""
- Confidence 保留5位小数
- 识别不出 → result 仅含 {"Index":N}
- 多人/多宠 → 同 Index 多条 result

示例：

2图（图1老人+狗，图2猫）→
{"list":[{"result":[{"Index":0,"X":0,"Y":0,"Height":0,"Weight":0,"Type":1,"SubType":1001,"AlbumType":2,"Translation":"老人","Emotion":"平静","Confidence":0.95210},{"Index":0,"X":0,"Y":0,"Height":0,"Weight":0,"Type":2,"SubType":2001,"AlbumType":4,"Translation":"宠物","Emotion":"","Confidence":0.88150}]},{"result":[{"Index":1,"X":0,"Y":0,"Height":0,"Weight":0,"Type":2,"SubType":2001,"AlbumType":4,"Translation":"宠物","Emotion":"","Confidence":0.92300}]}]}

2图均无识别 →
{"list":[{"result":[{"Index":0}]},{"result":[{"Index":1}]}]}

【强制】list长度=图片数。禁止省略{"list":[...]}。以{开头}结尾。
```

---

## 二、用户输入

输入为一张或多张图片（base64 或 URL），通过 API content 数组以 `image_url` 类型传入，提示词以 `text` 类型放在 content 数组最前面。

## 四、百炼模型对接建议

| 配置项 | 建议值 | 说明 |
|------|------|------|
| 模型 | `qwen3.6-flash` | 百炼性价比最高的视觉模型 |
| 端点 | `https://dashscope-us.aliyuncs.com/compatible-mode/v1/chat/completions` | 海外 OpenAI 兼容接口 |
| 认证 | `Authorization: Bearer <DASHSCOPE_API_KEY>` | 从百炼控制台获取 |
| temperature | 0 | 设为 0 是保证 JSON 格式稳定的关键 |
| max_tokens | 4096 | 多图多结果时需足够 token |
| stream | false | 非流式，一次性拿到完整 JSON |

### 格式稳定性保障

1. 提示词首尾均有【强制】标记，并强调外层 `{"list":[...]}` 结构不可省略
2. 提示词内含两组期望输出示例（正常识别 + 无结果）
3. temperature=0 保证最大确定性输出
4. 代码侧做双层容错：
   - 自动剥离 markdown 代码块再 JSON.parse
   - 兼容对象 `{...}` 和数组 `[...]` 两种提取模式
   - 若解析结果为数组（模型省略外层 list），自动包装为 `{list: result}`

## 五、对接代码骨架

```javascript
const SYSTEM_TEXT = `【强制】仅输出一行紧凑JSON {"list":[...]}。禁止markdown、换行、任何额外文字。

判断图中是否有人物/宠物，直接输出结果，不要描述画面、不要推理过程。按以下映射输出：

| AlbumType | Type | SubType | Translation |
|:---------:|:----:|:-------:|-----------|
| 0 | 1 | 1003 | 成年人 |
| 2 | 1 | 1001 | 老人 |
| 3 | 1 | 1002 | 小孩 |
| 4 | 2 | 2001 | 宠物 |

- X,Y,Height,Weight 始终填 0
- Emotion 人物填"平静"，宠物空""
- Confidence 保留5位小数
- 识别不出 → result 仅含 \`{"Index":N}\`
- 多人/多宠 → 同 Index 多条 result

示例：

2图（图1老人+狗，图2猫）→
{"list":[{"result":[{"Index":0,"X":0,"Y":0,"Height":0,"Weight":0,"Type":1,"SubType":1001,"AlbumType":2,"Translation":"老人","Emotion":"平静","Confidence":0.95210},{"Index":0,"X":0,"Y":0,"Height":0,"Weight":0,"Type":2,"SubType":2001,"AlbumType":4,"Translation":"宠物","Emotion":"","Confidence":0.88150}]},{"result":[{"Index":1,"X":0,"Y":0,"Height":0,"Weight":0,"Type":2,"SubType":2001,"AlbumType":4,"Translation":"宠物","Emotion":"","Confidence":0.92300}]}]}

2图均无识别 →
{"list":[{"result":[{"Index":0}]},{"result":[{"Index":1}]}]}

【强制】list长度=图片数。禁止省略{"list":[...]}。以{开头}结尾。`

/**
 * 时光相册图片识别（百炼 qwen3.6-flash API）
 * @param {string[]} imageUrls - 图片 URL 或 base64 数组
 * @returns {object} 识别结果 { list: [{ result: [...] }] }
 */
async function analyzeAlbumImages(imageUrls) {
  const content = [
    { type: 'text', text: SYSTEM_TEXT },
    ...imageUrls.map(url => ({
      type: 'image_url',
      image_url: { url }
    }))
  ];

  const response = await fetch('https://dashscope-us.aliyuncs.com/compatible-mode/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${DASHSCOPE_API_KEY}`
    },
    body: JSON.stringify({
      model: 'qwen3.6-flash',
      messages: [{ role: 'user', content }],
      temperature: 0,
      max_tokens: 4096
    })
  });

  const data = await response.json();
  let text = data.choices[0].message.content;

  // Strip markdown code blocks if present
  text = text.replace(/```json?\s*/gi, '').replace(/```\s*/g, '').trim();

  // Extract JSON (object or array)
  const objMatch = text.match(/\{[\s\S]*\}/);
  const arrMatch = text.match(/\[[\s\S]*\]/);

  let result;
  if (objMatch) {
    result = JSON.parse(objMatch[0]);
  } else if (arrMatch) {
    result = JSON.parse(arrMatch[0]);
  } else {
    throw new Error('No JSON found in response: ' + text);
  }

  // Fallback: if model returns array directly instead of {list:[...]}, wrap it
  if (Array.isArray(result)) {
    result = { list: result };
  }

  return result;
}
```
