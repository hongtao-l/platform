# oksee 简介（中文译本）

> 本文档为英文版的中文译文，仅供参考。如中英文版本存在不一致，以英文版本为准。

oksee 是中山市明阳良光照明有限公司推出的一款配套应用，能把您拥有的每一台智能摄像机汇聚到同一个手机屏幕中。

## 详细介绍

把一台新摄像机加入 oksee 只需几个步骤：将它接入家庭网络并绑定到您的账号，它便会出现在您的设备列表中。此后，您可以在任何时间、在任何地点打开实时画面，并在时间轴上向前翻看已存储的录像。当摄像机察觉到有人或有物体移动时，通知会即刻送达您的手机，让您不必亲自查看就能知道门口、院子或仓库正在发生什么。夜间成像、截图留存与设备分享补足了日常所需——家人可以观看同一台摄像机而无需交换密码——多台摄像机则并列在同一列表中，随时切换。
