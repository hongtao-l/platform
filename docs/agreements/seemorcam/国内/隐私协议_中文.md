# SeemorCam 隐私政策

> 版本：1.0
> 更新日期：2026年8月26日
> 生效日期：2026年8月26日

**傑德福有限公司**（以下简称"傑德福"或"我们"）是 SeemorCam 应用的开发者与运营方。本政策用于说明：在您使用 SeemorCam 及其相关服务期间，我们会采集、使用、存储与保护哪些个人信息，以及您就这些信息享有的各项权利。

SeemorCam 是一款面向宠物照护场景的应用，主要能力包括摄像机的远程查看与历史回放、宠物活动告警，以及智能喂食器的远程投喂、定时喂养与余粮监测。

请您在开始使用前通读本政策，重点留意加粗及特别提示的内容。若对任一条款有异议，请停止使用并通过文末方式与我们联系；继续使用即表示您已阅读、理解并同意本政策全部内容。

## 一、我们采集哪些信息

### 1. 账号信息

**注册**：创建账号时，您需提供手机号码或电子邮箱中的至少一项。我们会通过短信验证码或验证邮件核验该号码或邮箱的有效性；此类信息为注册所必需，缺失将无法完成注册。

除上述信息外，您可依功能页面提示自愿补充账号资料或关联第三方账号；这些信息并非使用 SeemorCam 所必需，拒绝提供不影响注册功能的正常使用。

**登录**：登录时，您需提供注册时使用的手机号码或邮箱，以及与之对应的验证码或密码。

### 2. 设备与视频信息

**设备绑定**：添加摄像机时，您需提交设备序列号（SN）供我们核验并完成绑定；同时我们会采集设备的在线、离线或休眠状态，用于向您实时展示设备运行情况。

**实时画面与录像回放**：查看实时画面或回放历史录像时，经您授权，我们会通过网络传输相应视频流。实时画面不会长期留存在我们的服务器上；录像文件以加密方式保存在设备本地或您所购买的云存储中。

### 3. 智能喂食器信息

使用喂食功能时，我们会记录您设置的定时喂养方案、手动投喂操作及喂食速度等参数，用于执行投喂指令、展示喂养记录与余粮情况。余粮读数来自设备端传感器的检测，仅供您参考。

### 4. 推送与通知

设备侦测到运动、宠物活动等事件时，我们会向您推送通知。您可在 App 内调整推送偏好或直接关闭推送。

### 5. 剪贴板

在登录、注册或设备分享过程中，我们可能读取您剪贴板中的特定内容（仅限规定格式的分享码或设备邀请码），用于自动填充或跳转至对应页面；该过程不会将剪贴板内容上传至服务器。

### 6. 设备权限与自动采集信息

为保障 App 正常、安全地运行并实现特定功能，我们可能申请系统权限并自动采集与设备相关的信息，包括设备型号、操作系统版本、唯一设备标识符（如 Android ID）、屏幕分辨率、网络硬件地址（MAC 地址）、IP 地址、应用安装列表及日志信息等，具体如下表：

| 业务场景 | 采集目的 | 采集方式 | 个人信息字段 |
|----------|----------|----------|--------------|
| 设备功能接入 | 保障核心功能运行与设备兼容 | 自动采集 | 客户端终端设备信息（型号/系统版本） |
| 安全风控 | 识别异常登录、防范账号盗用 | 自动采集 | 设备MAC地址、软件安装列表 |
| 故障分析 | 排查系统崩溃、优化稳定性 | 自动采集 | 日志信息 |
| 摄像机画面查看 | 实时视频查看、截图保存 | 用户授权 | 相机权限（扫码添加设备） |
| 语音对讲 | 设备端语音对讲 | 用户授权 | 麦克风权限 |
| 截图/录像保存 | 保存摄像机截图或录像到本地 | 用户授权 | 相册/存储权限 |
| 消息推送 | 接收设备告警通知 | 用户授权 | 通知权限 |
| 设备连接 | 设备Wi-Fi配网、蓝牙配网 | 用户授权 | 位置信息（Android Wi-Fi扫描）、蓝牙权限 |
| 运营分析 | 统计功能使用率、优化产品路径 | 自动采集 | 信息追踪（用户操作行为记录） |
| 网络服务 | 实现数据加载与服务器通信 | 自动采集 | 网络状态（WiFi/蜂窝数据） |
| 设备管理 | 设备合法性核验、保修服务绑定 | 自动采集 | 设备序列号（SN） |

> 关于 MAC 地址：仅用于设备识别、安全风控及匿名化统计；我们会对其做哈希加密，不直接关联您的身份。
>
> 关于应用安装列表：仅用于核查运行环境、衡量广告投放效果及兼容性分析；我们只采集与应用功能相关的必要列表，不会持续跟踪您的使用行为。

需要说明的是，绝大多数操作系统（Android、iOS 等）允许您在系统设置中自行管理各项权限；关闭权限可能导致部分功能无法正常使用。单独的终端设备信息与日志信息本身无法识别特定自然人；若需将这些非个人信息与其他信息结合以识别自然人身份，或与个人信息合并使用，则结合期间该等信息将按个人信息对待。除取得您的授权或法律法规另有规定外，我们会对此类信息做匿名化、去标识化处理。

除此之外，本服务暂不涉及以其他方式对外提供您的个人信息，我们也不会向任何第三方出售您的个人信息。
