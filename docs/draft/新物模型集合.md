# 新生态自定义模型设备端对外接入说明
## 一、配置数据流程说明
1. 生态平台给产品配置物模型，定义产品能力和默认配置数据
2. APP端根据产品物模型生成对应界面供用户操作
3. APP端修改数据后将新的配置数据设置到平台
4. 平台通知设备配置发生变更
5. 设备启动时或者接收到平台配置变更通知时主动向平台读取数据
6. 设备端SDK将读取到的数据与本地缓存比较，发生变更时主动对外进行回调通知
7. 固件端接收到设备端SDK配置变更回调通知后执行业务逻辑

## 二、接口说明
### 2.1 回调定义
自定义配置数据对外回调接口：平台下发自定义配置数据同步完成后，SDK 通过该回调将对应子配置的 JSON字符串通知给外部应用层。
```c
typedef int (*ZJ_PFUN_CUSTOM_CFG_CHANGED)(unsigned char *pucConfName, unsigned char *pucData);
```
参数说明：
|参数|说明|
| ---- | ---- |
|pucConfName|子配置名称，可选值：`Device` / `Camera` / `Micphone` / `Speaker` / `Screen` / `Algorithm`|
|pucData|子配置 JSON 字符串，回调调用结束后SDK内部自动释放指针内存|

### 2.2 回调接口设置
注册自定义配置变更回调，所有子配置变更共用同一个回调函数，通过 `pucConfName` 参数区分配置大类。
```c
_ZJ_API int ZJ_SetCustomCfgChangedCB(ZJ_PFUN_CUSTOM_CFG_CHANGED pfunCb);
```

## 三、配置数据说明
### 3.1 Device 大类
整体JSON结构：
```json
{
    "WorkModeModule":{},
    "LightModelModule":{},
    "IotModule":{}
}
```

#### 3.1.1 工作模式 WorkModeModule
JSON示例：
```json
"WorkModeModule":{
    "AovAutoSwitchPower": "69",
    "AovCaptureFrameRate": "5",
    "CustomModeConfig": "{\"DefaultExecMode\":\"0\",\"Plan\":[{\"OpenFlag\":\"1\",\"Week\":\"127\",\"StartTime\":0,\"EndTime\":86399,\"ExecMode\":1}]}",
    "LongPowerAutoSwitchPower": "63",
    "WorkMode": 0
}
```
字段说明：
|字段|说明|
| ---- | ---- |
|AovAutoSwitchPower|AOV模式自动切换电量阈值|
|AovCaptureFrameRate|AOV模式帧率，单位：秒/帧|
|CustomModeConfig|自定义模式定时配置字符串|
|LongPowerAutoSwitchPower|长电模式切换电量阈值|
|WorkMode|设备工作模式<br>0：超低功耗<br>1：低功耗<br>2：AOV<br>3：长电<br>4：自定义|

#### 3.1.2 灯光模式 LightModelModule
JSON示例：
```json
"LightModelModule":{
    "LightMode":"",
    "LightAutoModel": "{\"DefaultExecMode\":\"0\",\"Plan\":[{\"OpenFlag\":\"1\",\"Week\":\"127\",\"StartTime\":0,\"EndTime\":86399,\"ExecMode\":1}]}"
}
```
字段说明：
|字段|说明|
| ---- | ---- |
|LightMode|灯光模式<br>0：全彩模式<br>1：红外模式<br>2：智能模式<br>3：关闭<br>4：自定义模式|
|LightAutoModel|智能模式定时配置字符串|

#### 3.1.3 IoT 模块 IotModule

适用设备：非摄像机 IoT 设备。**香薰机**（三方自有ID蓝牙设备）使用本模块的香薰字段组；网关下挂子设备（温湿度/门磁/烟感等）使用本模块的传感器字段组。同一产品只下发与自己类型相关的那组字段。

JSON示例（香薰机）：
```json
"IotModule":{
    "SprayWakeSwitch": 1,
    "NozzleSelect": 0,
    "ScreenSwitch": 1,
    "SprayTimerSchedule": {
        "StartTime": 28800,
        "EndTime": 72000
    },
    "SprayMode": 0,
    "GearLevel": 1,
    "GearSprayDuration": 3,
    "GearSprayInterval": 20,
    "LeftSprayDuration": 5,
    "LeftSprayInterval": 10,
    "RightSprayDuration": 5,
    "RightSprayInterval": 10
}
```
字段说明：
|字段|说明|
| ---- | ---- |
|SprayWakeSwitch|休眠唤醒控制<br>0：休眠（停止雾化，关闭屏显与指示灯）<br>1：唤醒（恢复正常工作）|
|NozzleSelect|雾化喷口选择<br>0：混合（左右喷口同时工作）<br>1：左喷雾口（仅左喷口工作）<br>2：右喷雾口（仅右喷口工作）|
|ScreenSwitch|屏显开关<br>0：关闭<br>1：开启|
|SprayTimerSchedule|喷雾定时时段，对象类型（非 JSON 字符串），每日单个时段、无开关、无星期周期<br>StartTime：开始时间，int，单位秒，0~86399（28800=08:00）<br>EndTime：结束时间，int，单位秒，0~86399（72000=20:00），需大于 StartTime<br>取 `{"StartTime":0,"EndTime":86399}` 为全天，即不限制|
|SprayMode|喷雾模式<br>0：标准（喷香时长/间隔由档位决定）<br>1：自定义（喷香时长/间隔由用户手动设置）|
|GearLevel|喷雾档位，仅 SprayMode=0 时生效<br>1：1档<br>2：2档<br>3：3档|
|GearSprayDuration|当前档位对应的喷香时长，单位秒，设备上报，只读<br>仅 SprayMode=0 时有效；档位 → 参数的映射由固件内置|
|GearSprayInterval|当前档位对应的喷香间隔，单位分钟，设备上报，只读<br>仅 SprayMode=0 时有效|
|LeftSprayDuration|左喷口单次喷香时长，单位秒，3~20|
|LeftSprayInterval|左喷口两次喷香之间的停喷间隔，单位分钟，3~50|
|RightSprayDuration|右喷口单次喷香时长，单位秒，3~20|
|RightSprayInterval|右喷口两次喷香之间的停喷间隔，单位分钟，3~50|

> 恢复出厂设置复用 `DeviceModule.FactoryReset`（服务类，不走本配置下发，设备离线时直接拒绝而非暂存），见 `香薰机物模型定义.md` §3.11。
> 完整的 `dataDef`（平台能力池配置）见 `香薰机物模型定义.md`。

### 3.2 Camera 大类
整体JSON结构：
```json
{
    "Camera": {
        "CamList": [
            {
                "CamID": 0,
                "Properties": {}
            }
        ]
    }
}
```

`Properties` 为当前镜头的能力模块集合，各能力按模块名分组（与 Device 大类模块嵌套一致）。以人形画框开关为例：

```json
"Camera": {
    "CamList": [
        {
            "CamID": 0,
            "Properties": {
                "ImageModule": {
                    "HumanFrameSwitch": 1
                }
            }
        }
    ]
}
```

字段说明：
|字段|所属分类|说明|
| ---- | ---- | ---- |
|CamList|Camera|镜头列表（多镜头）|
|CamList[i].CamID|Camera|镜头ID|
|CamList[i].Properties|Camera|镜头能力模块集合（按模块名分组）|
|Properties.ImageModule|ImageModule|图像采集模块|
|Properties.ImageModule.HumanFrameSwitch|ImageModule|人形画框开关<br>0：关闭<br>1：开启|

### 3.6 Algorithm 大类

所有算法类能力遵循同一标准格式，以算法ID为 Key 区分不同算法（如 3200=运动侦测、3201=人形侦测、3202=猫狗侦测），每个算法内字段结构一致；算法内 `DetectType` 仅包含该算法支持的侦测类型，未支持的无需下发。

整体JSON结构：
```json
{
    "Algorithm": {
        "3200": {},
        "3201": {},
        "3202": {}
    }
}
```

#### 3.6.1 算法标准格式（以 3200 为例）

JSON示例：
```json
"3200": {
    "AlgorithmSwitch": 1,
    "Sensitivity": 1,
    "DetectType": {
        "MotionDetect": 1,
        "PersonDetect": 1,
        "VehicleDetect": 0,
        "CatDetect": 0,
        "DogDetect": 0
    },
    "ScheduledDetect": [
        {
            "Switch": 1,
            "StartTime": 0,
            "EndTime": 86399,
            "Week": 127
        }
    ],
    "ZoneDetect": [
        {
            "ZoneId": 1,
            "X1": 1000, "Y1": 1000,
            "X2": 9000, "Y2": 1000,
            "X3": 9000, "Y3": 9000,
            "X4": 1000, "Y4": 9000,
            "X5": 0, "Y5": 0,
            "X6": 0, "Y6": 0
        }
    ],
    "SoundAlarmSwitch": 0,
    "SoundAlarmCount": 3,
    "CustomAlarmAudio": "",
    "LightAlarmSwitch": 0,
    "LightAlarmDuration": 5
}
```

字段说明：
|字段|说明|
| ---- | ---- |
|AlgorithmSwitch|算法开关<br>0：关闭<br>1：开启|
|Sensitivity|灵敏度<br>0：高<br>1：中<br>2：低|
|DetectType|侦测类型，对象类型；key 为侦测类型标识，value 为开关<br>0：关闭<br>1：开启|
|DetectType.MotionDetect|运动侦测开关|
|DetectType.PersonDetect|人形侦测开关|
|DetectType.VehicleDetect|车辆侦测开关|
|DetectType.CatDetect|猫侦测开关|
|DetectType.DogDetect|狗侦测开关|
|ScheduledDetect|定时侦测时段数组（最多10个）|
|ScheduledDetect[i].Switch|该时段是否启用<br>0：关闭<br>1：开启|
|ScheduledDetect[i].StartTime|开始时间，int，单位秒，0~86399（如 28800=08:00:00）|
|ScheduledDetect[i].EndTime|结束时间，int，单位秒，0~86399（如 72000=20:00:00）|
|ScheduledDetect[i].Week|生效日掩码<br>bit0=周日(1) bit1=周一(2) … bit6=周六(64)<br>127=每天，多选叠加|
|ZoneDetect|侦测区域数组（最多8个）|
|ZoneDetect[i].ZoneId|区域ID，从1开始|
|ZoneDetect[i].X1~X6|顶点X坐标，int 0~10000，值/10000=归一化坐标|
|ZoneDetect[i].Y1~Y6|顶点Y坐标，int 0~10000|
||4边形使用顶点1~4，6边形使用顶点1~6|
|SoundAlarmSwitch|声音告警开关<br>0：关闭<br>1：开启|
|SoundAlarmCount|声音告警触发次数<br>1：1次<br>2：2次<br>3：3次<br>5：5次<br>10：10次|
|CustomAlarmAudio|自定义告警音频内容（字符串）|
|LightAlarmSwitch|灯光告警开关<br>0：关闭<br>1：开启|
|LightAlarmDuration|灯光告警持续时长（秒），1~60|

#### 3.6.2 猫狗侦测算法（3202）

猫狗侦测算法只包含「侦测类型」能力项，不含算法开关、灵敏度、定时侦测、自定义侦测区域、告警联动等其它字段。

JSON示例：
```json
"3202": {
    "DetectType": {
        "CatDetect": 0,
        "DogDetect": 0
    }
}
```

字段说明：
|字段|说明|
| ---- | ---- |
|DetectType|侦测类型，对象类型，仅含猫侦测、狗侦测两种侦测类型|
|DetectType.CatDetect|猫侦测开关<br>0：关闭<br>1：开启|
|DetectType.DogDetect|狗侦测开关<br>0：关闭<br>1：开启|
