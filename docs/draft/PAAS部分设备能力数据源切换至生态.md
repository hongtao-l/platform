# 产品功能点清单 — 功能定义与配置

> 从 iot-platform 产品管理 → 继续开发 → 功能定义与配置 提取，按功能点+所属模块组织。
> 江能发/广春APP通过HTTP协议获取设备能力。

---

## 一、设备能力

### 1. 联网方式
- 联网方式（有线 / WIFI / 移动网络）
- 配网方式（AP / 声音 / smartlink / 摄像机识别二维码添加 / 局域网 / APP扫码添加 / 蓝牙添加）
- 默认配网方式

### 2. 对讲设置
- 支持对讲方式（不支持 / 半双工 / 全双工）

### 3. 电池设置
- 是否有电池（有 / 无）
- 充电状态显示电量能力（支持 / 不支持）

### 4. 工作模式
- 是否支持切换工作模式（支持 / 不支持）
- AOV能力（支持 / 不支持）

### 5. 唤醒能力
- 是否支持唤醒（不支持 / 本地 / 远程 / 本地+远程）

### 6. 指示灯
- 是否有状态指示灯

### 7. 红外灯
- 是否支持红外灯（是 / 否）
- 红外切换模式（自动 / 手动+自动 / 手动）

### 8. 喇叭配置
- 是否有喇叭（是 / 否）
- 一键报警能力（支持 / 不支持）
- 音量调节（支持 / 不支持）
- 自定义铃声（支持 / 不支持）

- 人形坐标能力（支持 / 不支持）
