# 产品配置 JSON 定义 — 总览

平台按业务把产品配置拆成 **4 个独立接口**，APP 分别按需拉取、分别缓存：

| # | 配置文件 | 内容 | 对应平台位置 |
|---|---|---|---|
| 1 | [产品基础配置JSON定义.md](产品基础配置JSON定义.md) | 设备类型、联网方式、配网方式、优先配网方式 | 产品开发 · 基础信息 |
| 2 | [产品物模型配置JSON定义.md](产品物模型配置JSON定义.md) | 能力项（属性 / 服务 / 事件 / 策略） | 物模型管理 · 能力库 |
| 3 | [产品APP配置JSON定义.md](产品APP配置JSON定义.md) | 分辨率、插值、播放限制、假三目、画面分屏、灯控、低电量 | 产品开发 · 步骤2 APP 控制面板配置 |
| 4 | [产品安装指引配置JSON定义.md](产品安装指引配置JSON定义.md) | 安装引导步骤（图/动图/视频 + 多语言） | 产品开发 · App功能配置 · 安装指引 |

## 拆分理由

- **变化频率不同**：基础配置几乎不变；APP 配置按运营调整；安装指引是文案物料，改动最频繁。拆开后各自缓存、各自刷新，不用为改一段文案把整包配置重拉。
- **依赖方不同**：物模型配置是设备与 APP 共用（量大，450+ 参数）；基础配置与 APP 配置只服务 APP；安装指引只服务激活页。
- **失败隔离**：某一个接口失败时，其它区块仍能正常渲染。

## 通用约定

1. 每个接口都返回 `updated_at`，便于客户端比对缓存。
2. 未识别的枚举值：APP 回退默认表现，不得白屏。
3. 新增字段不升版本号，APP 忽略未知字段。
4. 所有枚举值固定小写英文，显示文案由 APP 本地化。
