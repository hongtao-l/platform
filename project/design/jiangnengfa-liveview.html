底部标签栏 / 操作条

面板区高度 = 屏幕高 − 顶部栏 − 视频区 − 圆钮行 − 底栏

  • 面板区 ≥ 170px → A 样式：显示事件 / 云台 / 操作分页面板
  • 面板区 < 170px → B 样式：隐藏面板，功能平铺到贴底操作条（左右滑动）
  • 所有布局统一按此判定，条字形不再固定 B；只是它整体较高，多数手机仍会落到 B

其他规则

  • 5 种画面布局：单屏 / 双屏 / 品字形 / 条字形 / 四宫格，按路数与是否全屏决定可选项
  • 画面始终完整显示，不裁切、不拉伸；放不下时整体等比缩小留黑边
  • 170px 的由来：事件页需 128px、操作页需 118px、云台页需 270px（不足时方向盘等比缩放）；取 170 保证事件与操作完整显示，云台方向键约 45px（≈ 44pt 触控下限）
  • 点击画面显示 / 隐藏叠加信息（镜头类型、时间、清晰度、画面形式、全屏）
  • 云台只作用于当前选中的那一路；选中枪机时云台置灰
  • 只有 1 路时隐藏布局切换入口
